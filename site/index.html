CASA0005

Geographic Information Systems and Science

Term 115 credits90% exam10% other assessmentFHEQ Level 7

這是一門以實作為主的 GIScience 與 spatial analysis 課程：你會從真實、未必乾淨的地理資料開始，完成資料清理、空間資料整合、地圖製作、空間統計與結果解釋。課程的目的不是只會操作軟體，而是能夠用空間資料回答一個具體的城市、環境或社會地理問題。

Complete module dossier完整課程內容與你會學會的能力
課程工作 R QGIS Python 統計方法 學習成果 先備知識 學習負擔 Assessment

一、這門課具體在做什麼？

典型工作流程是：提出 spatial question 或 hypothesis → 找到 ONS、OSM、政府或其他 contemporary datasets → 清理與整理資料 → 對齊空間範圍與座標系統 → 用 R／QGIS 做空間分析 → 製作地圖與統計圖 → 評估 uncertainty、限制與結果是否合理。

公開 practical handbook 特別強調，課程會使用接近真實研究的資料；資料不會永遠是乾淨、可以直接分析的狀態，因此 data wrangling、格式轉換與錯誤排查本身就是課程的一部分。

二、R：主要分析工具

  • 讀取、清理、tidy 與整理資料。
  • 處理 vector、raster、point、polygon 等 spatial data。
  • 進行 spatial joins、attribute／geometry 整合、格式轉換與 CRS 處理。
  • 製作統計圖、靜態地圖與具備 cartographic standards 的視覺化。
  • 用 R packages 執行 spatial statistics、pattern analysis 與 regression。
  • 透過 RMarkdown／GitHub 建立較可重現的分析流程。

三、QGIS：基本 GIS 與地圖工作

  • 載入、查看與檢查不同空間圖層。
  • 理解 projections、coordinate reference systems 與 spatial extent。
  • 做基本的 spatial filtering、buffer、point-in-polygon 與空間資料整理。
  • 協助檢查資料、操作圖層與輸出地圖。
  • QGIS 是課程的一部分，但官方描述是「basic concepts」；主要分析主軸仍然是 R。

四、Python 可以嗎？

目前 UCL CASA0005 官方頁面與公開 handbook 都把 R 列為主要 data science programming language，並沒有把 Python 列為這門課的主要教學工具。因此 Python 可以作為你自己的輔助工具，但不能自行假設正式 coursework 一定接受 Python 取代 R；實際作業規則要以當年度 Moodle assessment brief 為準。

五、會用到的統計與空間分析

  • Descriptive statistics：資料型態、分布、histogram、基本空間資料描述。
  • Point pattern analysis：Kernel Density Estimation、Quadrat Analysis、Ripley’s K。
  • Spatial clustering：DBSCAN 等以空間位置判斷群聚的方法。
  • Spatial autocorrelation：Moran’s I、Geary’s C、Getis-Ord 與 LISA。
  • Spatial operations：areal interpolation、point-in-polygon、buffer、hot-spot analysis。
  • Regression：linear／multiple regression、bootstrap 與 regression assumptions。
  • Spatial regression：spatial lag、spatial error 與 Geographically Weighted Regression（GWR）。

六、學完後應該能做到什麼？

  • 用 QGIS 與 R 支援 GIScience 技術的應用。
  • 按照 cartographic standards 製作合適的地圖。
  • 清理、連接、轉換與管理空間資料。
  • 選擇適合的 spatial analysis 回答不同空間問題。
  • 理解 geographic data 的 representation、uncertainty 與資料品質問題。
  • 批判性地解釋 spatial statistical analysis，而不是只報告一個數字。
  • 比較不同全球 spatial datasets 的優點、限制與適用情境。

七、統計基礎要到什麼程度？

官方沒有要求你入學前已經會 GIS 或 R，但課程進度很快。實際上，先具備基本 descriptive statistics、資料分布、圖表閱讀、相關與 regression 結果解讀會很有幫助；更進階的 spatial statistics 會在課程中逐步建立。

準備方向：不用先把所有 R syntax 或 QGIS 工具背熟，但最好先理解平均數、變異、分布、correlation、regression 的基本概念，以及「空間上相鄰的資料可能不是獨立的」這個核心問題。

八、學習負擔與上課方式

  • Term 1，15 credits，FHEQ Level 7。
  • 官方標示為 in-person teaching。
  • 公開 handbook 以每週 lecture／practical 約 3 小時，另加約 12 小時自主學習估算。
  • 沒有 GIS 或 R 背景可以開始，但不代表課程會慢慢教；需要持續完成 practical 與課後練習。

九、Exam 與 assessment

  • 2026/27 UCL Module Catalogue 目前列為 90% Exam。
  • 另外列有 10% Other form of assessment，但公開頁面沒有說明具體是什麼形式。
  • 目前公開資訊沒有確認是上機考、紙筆考、online exam、presentation，或是否可以在考試中使用 R／QGIS。
  • 因此不能把它寫死成「一定是上機考」或「一定有 presentation」；正式細節要看當年度 Moodle 或 module team 的 assessment brief。

官方來源： UCL Module Catalogue：CASA0005 · CASA0005 online practical handbook

CASA0007

Quantitative Methods

Term 115 credits100% courseworkFHEQ Level 7

這門課建立城市與空間研究需要的 quantitative foundation：從描述資料、機率與假設檢定，到迴歸、multilevel regression、降維與 clustering，重點是能用統計模型描述資料、建立分析並解讀結果。

Complete module dossier統計方法、數學概念與城市資料分析
課程工作統計方法工具上課方式學習成果先備知識Assessment

一、這門課具體在做什麼？

你會從城市或空間資料開始，先描述資料的型態與分布，再選擇合適的統計工具，建立模型、檢查關係，最後把模型結果轉化成可以解釋的 spatial／urban insight。它不是只背公式，而是訓練你判斷「這份資料適合怎麼分析」以及「分析結果能不能支持原本的研究問題」。

官方明確說明這是一門介紹 statistical and mathematical tools 的碩士課程，目標是建立概念理解，而不是要求非常進階的 technical mathematics；官方也表示不假設學生已有大量先備知識。

二、會學到哪些統計與數學方法？

  • Data description and representation：理解資料如何被整理、描述與呈現。
  • Probability distributions：用機率分布理解不確定性與資料可能的生成型態。
  • Hypothesis testing：把研究問題轉成可檢驗的統計問題，理解檢定與結果解讀。
  • Linear algebra：建立後續模型與多變量分析需要的矩陣／向量概念。
  • Measuring relationships：衡量變數之間的關係，並判斷關係的強弱與限制。
  • Regression：用迴歸建立解釋或預測模型。
  • Multiple regression：同時處理多個解釋變數，理解控制其他因素後的關係。
  • Multilevel regression：處理具有層級結構的資料，例如個體位於 neighbourhood、neighbourhood 位於城市。
  • Dimensionality reduction：把複雜、多變量資料轉成較容易理解的低維結構。
  • Clustering：依資料特徵找出群組或型態，不預先假定每筆資料屬於哪一群。

三、會使用哪些工具？

  • Python：官方列出的主要程式工具，用於統計與資料分析實作。
  • Jupyter：以 notebook 形式交錯撰寫程式、分析與解釋。
  • GitHub／Git：用於版本控制、保存分析工作與協作。
  • Podman：官方 software list 中列出的 container 工具。

官方目前沒有把 R 列為 CASA0007 這個 module page 的主要 software list；因此這門課的明確官方工具訊息是 Python、Jupyter、GitHub、Git 與 Podman。

四、上課方式與實作

  • Term 1、15 credits、FHEQ Level 7，官方標示為 in-person。
  • 10 次 weekly lectures，加上 10 次 weekly practical sessions。
  • 實作的角色是把統計概念放回 spatial／urban context，練習從資料、模型到 interpretation 的完整流程。
  • 官方頁面沒有公開每一次 practical 的逐週題目或固定資料集，因此這張 card 不把未公開的案例自行寫成正式課綱。

五、學完後應該能做到什麼？

  • 描述與呈現城市／空間資料。
  • 理解並選用適合研究問題的統計與數學工具。
  • 建立 regression、multiple regression 或 multilevel regression 等模型。
  • 用 dimensionality reduction 與 clustering 探索複雜資料。
  • 從模型輸出推導 spatial／urban insight，而不是只報告一個數字。
  • 辨認資料、模型假設與解釋之間的限制。

六、需要什麼先備知識？

官方課程描述以「conceptual understanding rather than technical mathematics」為定位，並寫明 little or no prior knowledge assumed。因此不需要先成為統計或數學專家；但先複習平均數、變異、機率、圖表閱讀、correlation 與 regression 的基本直覺，會讓 Term 1 的進度比較容易跟上。

七、Exam 與 assessment

  • 2026/27 UCL Module Catalogue 目前列為 100% Coursework。
  • 成績類型為 numeric marks。
  • 公開 module page 沒有確認是上機考、筆試、presentation、report 或哪一種固定作業格式；實際 brief 要以當年度 Moodle 與 module team 公告為準。

官方來源： UCL Module Catalogue：CASA0007 · CASA0007 module preview

CASA0001

Urban Systems Theory

Term 115 credits100% courseworkFHEQ Level 7

這是整個課程的城市理論與社會科學 foundation：把 urbanisation、systems and complexity、urban form、mobility、社會空間差異與 urban governance 放在同一個分析框架中。

Complete module dossier理解城市如何作為社會、空間與複雜系統運作
課程問題核心主題分析工具上課方式學習成果先備知識Assessment

一、這門課具體在問什麼？

課程用 social science 與 urban theory 來理解城市，而不是把城市只當成一組地圖或數據。你會練習把一個城市問題拆成不同尺度的社會、空間、制度與治理關係，再思考這些關係如何形成 urban system，以及如何轉化成有意義的 research inquiry。

它是 programme 的 conceptual foundation，後續的 spatial analysis、urban modelling、smart cities 與 dissertation 都可以回到這裡的系統思考與城市理論。

二、會學哪些城市理論與主題？

  • Urbanisation、城市發展與 urban geography。
  • Systems theory、complexity theory 與城市作為互相連結的系統。
  • Urban form and function：城市形態如何和功能、活動與空間結構連在一起。
  • Mobility、transport 與城市中的流動。
  • Socio-spatial differentiation：不同群體與地區如何產生空間差異。
  • Urban health 與城市環境、社會結果的關聯。
  • Urban planning、urban governance 與制度如何影響城市。
  • Systems thinking、causal diagrams 與其他用來整理城市關係的 analytical tools。

三、會用什麼工具？

這門課的官方定位是理論、概念與社會科學 foundation，module page 沒有列出像 R、Python 或 QGIS 這樣的固定 software requirement。你比較會使用的是 systems thinking、概念框架、causal diagrams、文獻與案例的批判性分析；具體工具依當年度 lectures、readings 與 coursework brief 而定。

四、上課方式與學習活動

  • Term 1、15 credits、FHEQ Level 7，官方標示為 in-person。
  • 10 次 weekly 2-hour lectures。
  • 另有 optional support hour，讓學生處理閱讀、概念或 coursework 上的問題。
  • 官方頁面沒有公開固定的逐週 presentation 或 exam format，因此不把課堂討論形式誤寫成正式 assessment。

五、學完後應該能做到什麼？

  • 把 systems thinking 與 social science theories 應用到城市問題。
  • 概念化 cities、society 與 space 之間的關係。
  • 對 urban systems 進行 critical thinking，而不是只接受單一解釋。
  • 參與關於城市與空間的 scientific discourse。
  • 提出有意義、可以進一步研究的 urban research inquiry。

六、需要什麼先備知識？

官方 module page 沒有列出 CASA0001 的硬性 prerequisite。對這門課最有幫助的是先接觸 urban geography、城市規劃、社會科學閱讀與基本 systems thinking；不需要先會 GIS、R 或 Python 才能理解這門課的核心。

七、Exam 與 assessment

  • 2026/27 UCL Module Catalogue 目前列為 100% Coursework，並標示為 2 assessments。
  • 成績類型為 numeric marks。
  • 公開頁面沒有進一步確認兩項 coursework 是 essay、report、presentation 或其他形式；實際格式要以當年度 Moodle assessment brief 為準。

官方來源： UCL Module Catalogue：CASA0001

CASA0010

Urban Spatial Science Dissertation

Terms 2–360 credits100% dissertation / projectFHEQ Level 7

這不是一門固定內容的 lecture module，而是一個 60-credit original research project：你要在 supervisor 與 Programme Director 的支持下，定義問題、蒐集資料、分析、視覺化並完成一篇和 urban spatial science 有關的 dissertation。

Complete module dossier從研究問題到完整 dissertation 的獨立研究
研究工作題目與 supervisor資料與方法時間與學習方式研究能力Assessment

一、Dissertation 具體在做什麼？

你要把前面 Term 1、Term 2 所學的 urban theory、GIS、quantitative methods、spatial data science 或其他 pathway skills，組成一個自己的 research project。工作通常包括界定研究問題、選擇資料、設計方法、執行分析、製作視覺化、討論結果與限制，最後以 dissertation／extended research project 的形式呈現。

官方描述強調這是一個 unique individual piece of work，重點包括 data collection、analysis、visualisation，以及和 policy 或 social-science applications 的連結。

二、題目如何決定？

  • 應該在前期 projects 與 taught courses 中就開始規劃 research idea，不是等到最後一刻才開始。
  • 題目會在 dissertation supervisor 與 Programme Director 的支持／討論下定義。
  • 研究可以和城市、空間、資料、政策或社會科學應用連結。
  • 官方提到有可能和 industry partner 合作，但這不是每位學生都必然會有的安排。

三、會用哪些工具與方法？

CASA0010 沒有一套對所有學生都相同的 software list；工具會依你的研究問題、資料與 supervisor 建議決定。可能延續 GIS、R、Python、SQL、web visualisation、remote sensing 或 modelling 等前面課程技能，但這張 card 不把某一套工具寫成 dissertation 的硬性要求。

真正重要的是方法和問題要對得上：你要能說明資料如何取得、為什麼選這個分析方法、結果能回答什麼、以及 uncertainty、bias、data quality 與研究限制。

四、時間與上課方式

  • 涵蓋 Terms 2 and 3，共 60 credits、FHEQ Level 7，官方標示為 in-person。
  • 它主要是 supervised independent research，不是每週固定內容相同的 lecture。
  • 官方 course page 建議 dissertation 應是最後完成的主要 activity；因此前面的 modules、projects 與資料技能會直接影響你的研究準備。
  • 公開 module page 沒有列出固定每週時數或統一的 software／weekly practical schedule。

五、完成後會具備什麼研究能力？

  • 把抽象的 urban question 轉成可執行的研究設計。
  • 獨立蒐集、整理、分析與視覺化 spatial／urban data。
  • 把 quantitative、qualitative、computational 或 GIS 方法和研究問題對齊。
  • 批判性解釋結果、限制、uncertainty 與政策／社會意義。
  • 以清楚、可追溯的 dissertation 報告完整研究過程。

六、Exam 與 assessment

  • 2026/27 UCL Module Catalogue 目前列為 100% Dissertations, extended projects, and reports。
  • 成績類型為 numeric marks。
  • 這不是傳統筆試；公開分類確認的是 dissertation／extended project／report，但公開 module page 沒有列出更細的字數、口試、presentation 或 viva 要求。
  • 正式格式、截止日期、proposal 與 supervisor milestones 要以當年度 dissertation handbook、Moodle 與 Programme Director 公告為準。

官方來源： UCL Module Catalogue：CASA0010

CASA0013

Foundations of Spatial Data Science

Term 115 creditsCASA optional不屬於目前列出的具名 pathwayFHEQ Level 7

這是一門以 Python 為核心的 spatial data science foundation：從資料清理、視覺化到 interpretation／presentation，並同時討論技術實務、reproducibility、資料倫理與真實城市資料問題。

Complete module dossierPython、資料 pipeline 與 spatial data science practice
課程工作Python 主題實務與倫理上課方式先備與設備學習成果Assessment

一、這門課具體在做什麼？

你會練習一個 end-to-end spatial data science pipeline：取得或讀入資料、清理與整理、用 geographic／quantitative／textual lenses 探索、做視覺化、解讀結果，再把結果清楚地呈現給別人。官方說明它補足 CASA0007 與 CASA0005，把統計、地理與計算概念放進同一個實作流程。

官方也以真實問題與資料作為脈絡，例如 Airbnb／London 類型的城市資料問題；它不是只教 Python syntax，而是把程式能力、資料判斷、批判性思考與 communication 放在一起。

二、Python 會學什麼？

  • Variables、lists、dictionaries 等基本資料結構。
  • Functions、libraries、methods 與 classes。
  • 用 Python 處理 large real-world data。
  • 以 numeric、spatial 與 textual perspectives 看資料。
  • 從 computational notebooks 逐步建立可讀、可重現的分析。

三、技術實務、reproducibility 與倫理

  • 用 command line、Docker／Podman、Git／GitHub 與 Quarto 建立較可重現的工作流程。
  • 討論資料選擇、呈現方式、解讀與 communication，而不是只追求圖表好看。
  • 理解 spatial data science 的 technical practices 以及更廣泛的 ethics。
  • 重點包含如何把結果呈現給不同讀者，以及資料與分析如何影響他人對城市的理解。

四、上課方式與活動

  • Term 1、15 credits、FHEQ Level 7，官方標示為 in-person。
  • 10-week flipped format：課前 pre-recorded videos，課堂進行 discussion、presentation 與實作。
  • 使用 computational notebooks 進行練習。
  • 課程 assessment 主要透過 group work 完成；這不代表每一個課堂活動都等於正式 assessment。

五、先備知識與設備

  • 對 Python 初學者尤其有幫助；官方另建議初學者參加 Code Camp。
  • 需要能處理 local development、notebooks 與 containers 的電腦環境。
  • 官方建議 24GB RAM；16GB 可以運作但效能可能較差，並建議保留超過 50GB free storage。
  • 課程使用 FOSS；Markdown editor 與 Git GUI 可選，不是固定要求。

六、學完後應該能做到什麼？

  • 用 Python 完成一個從資料到結果的 spatial data workflow。
  • 清理、探索、視覺化並解讀 real-world spatial data。
  • 使用 Git／GitHub、containers 與 Quarto 支援 reproducibility。
  • 解釋資料選擇、設計與呈現如何改變研究訊息。
  • 批判性思考 spatial data science 的技術、倫理與社會影響。

七、Exam 與 assessment

  • 2026/27 UCL Module Catalogue 列為 85% Group activity（2 assessments）+ 15% Coursework，numeric marks。
  • 正式兩項 group activity 與 15% coursework 的名稱、題目、交件格式和日期以當年度 Moodle brief 為準。
  • 2025/26 公開課程頁曾採 30% timed open-book Python exam、25% 可重現小組資料分析、35% 報告/展示、10% self/peer evaluation；這是舊年度版本，不能當成今年評量比例或題目。

官方來源： UCL Module Catalogue：CASA0013 · CASA Code Camp

CASA0002

Urban Simulation

Term 215 creditsCASA optionalSmart Cities and Urban PolicyUrban Modelling and SimulationFHEQ Level 7

以 complexity science、spatial interaction models 與 network science 建立城市系統模型，分析人與地點之間的流動、交通節點、通勤網絡、社群結構與 resilience。

Complete module dossierSpatial interaction models 與 network science
模型在做什麼Spatial interactionNetworksPython 與實作先備知識學習成果Assessment

一、這門課具體在模擬什麼？

課程用 mathematical modelling 把城市視為一個具有互動、流動與複雜結構的 system。你會處理 people／places 之間的 interaction，以及個別互動如何形成整體 urban structure；官方特別以 transport、commuting flows、transport-node centrality、resilience 與 community detection 作為應用脈絡。

二、Spatial interaction models

  • 理解 flows 如何在不同 area 之間發生，並把各地的 location characteristics 與 spatial distribution 納入模型。
  • 分析 constraints 與 parameters，理解模型如何受到條件限制。
  • 接觸 entropy maximisation 與 retail application。
  • 用 Python 實作、calibrate 並選擇合適的 spatial interaction model。
  • 理解模型是對城市互動的抽象，不是城市本身；因此要檢查假設與解釋限制。

三、Network science

  • 把 complex system 表示成 nodes、links 與 adjacency matrices。
  • 計算與解釋 centrality，區分 local／global measures。
  • 使用 community detection 找出網絡中的群組結構。
  • 理解 random networks、null hypotheses 與不同 link types。
  • 分析 network resilience，並用 Python 做 spatial network visualisation。
  • 認識 Agent Based Modelling／Cellular Automata 與 network modelling 的關聯。

四、Python 與課堂實作

  • 官方課程以 code-based practical 為核心，會用 Python 實作與校準模型、處理矩陣／向量與視覺化 network。
  • 課程每週同時包含 lecture 與 practical，實作會把數學概念轉成可執行的程式。
  • 這門課需要能閱讀、修改與執行提供的 Python code；不是只看理論。

五、先備知識與修課順序

  • 非程式背景學生官方 strongly advised 先修 CASA0013 或同等能力。
  • 需要 basic Python 或其他程式語言能力。
  • 需要複習 matrices、vectors 等數學表示法，才能跟上 model 與 network content。

六、學完後應該能做到什麼？

  • 建構、calibrate 與選擇 spatial interaction models。
  • 說明模型 constraints、parameters、entropy maximisation 與 urban application。
  • 建構 networks 與 adjacency matrices，並解釋 centrality。
  • 用 community detection 分析群組結構。
  • 討論 network resilience 與 spatial network visualisation。
  • 辨認 spatial interaction、ABM、CA 與 network approaches 的差異與關係。

七、Exam 與 assessment

  • 2026/27 目前列為 100% Coursework，numeric marks。
  • 公開 module page 沒有確認 coursework 的具體形式是 coding project、report、上機考或 presentation；要以當年度 assessment brief 為準。

官方來源： UCL Module Catalogue：CASA0002

CASA0006

Data Science for Spatial Systems

Term 215 creditsCASA optionalData VisualisationUrban Modelling and SimulationFHEQ Level 7

進階 spatial data science 與 machine learning module：從 supervised learning workflow、模型評估與 cross-validation，到 tree-based methods、neural networks、graph neural networks、model interpretation 與 MLOps。

Complete module dossier以 machine learning 分析 spatial systems
ML workflow模型方法工具進階主題先修學習成果Assessment

一、這門課具體在做什麼？

課程把 machine learning 放回 spatial systems 與 urban applications，而不是只教一組演算法。你會從定義問題開始，選擇 metrics、切分 train／test data、做 cross-validation、解讀 model，並思考模型在真實城市資料上是否可靠。

它是 CASA0007 Quantitative Methods 之後的進階選修；官方明確預期學生先完成 CASA0007。

二、會學哪些 machine learning 方法？

  • Introductory machine learning concepts。
  • Supervised learning metrics 與完整 workflow。
  • Tree-based methods。
  • Neural networks。
  • Graph neural networks，處理 graph／network 結構的資料。
  • Model interpretation 與 feature selection。
  • Classification／regression 類型的 urban／spatial applications。

三、會使用哪些工具？

  • Python：主要 data science programming tool。
  • Jupyter：以 notebook 進行分析與實作。
  • GitHub／Git：版本控制與協作。
  • Podman：官方 software list 中列出的 container 工具。

四、模型可靠性與 production thinking

  • Imbalanced data：資料類別比例不平衡時，評估結果可能如何失真。
  • MLOps：把模型放入較完整、可管理的資料／部署流程。
  • Testing ML systems：檢查 machine learning system 是否按照預期工作。
  • Model interpretation：不要只追求 prediction accuracy，也要理解模型用了什麼訊號、結果能不能被解釋。

五、先修與課程位置

  • 官方 restriction：expected to have completed CASA0007 Quantitative Methods。
  • 需要能理解基本統計、資料分析與 model evaluation；Python／Jupyter 經驗會很有幫助。
  • 官方 module page 沒有列出 CASA0013 為硬性 prerequisite，但如果 Python 基礎薄弱，先補 spatial data science foundation 會比較實際。

六、學完後應該能做到什麼？

  • 設計 supervised learning workflow 並選擇合適的 metrics。
  • 正確使用 train／test split 與 cross-validation。
  • 建立與比較 tree-based models、neural networks 與 graph neural networks。
  • 解釋 model、選擇 features，並處理 imbalanced data。
  • 把 machine learning 方法連到 real-world urban／spatial applications。
  • 對 ML system 的測試、部署與限制做批判性判斷。

七、Exam 與 assessment

  • 2026/27 目前列為 100% Coursework，numeric marks。
  • 公開頁面沒有確認 coursework 是 coding assignment、report、project、上機考或 presentation；正式格式以當年度 Moodle brief 為準。

官方來源： UCL Module Catalogue：CASA0006 · CASA0006 module preview

Complete module dossierSmart urbanism 的技術、政策與治理脈絡

一、這門課具體在研究什麼？

課程不把 smart city 簡化成「城市裝更多 sensors」或「做一個 dashboard」，而是問：哪些 economic、social、technological contexts 形成 smart urbanism？哪些 actors、institutions 與 partnerships 生產它？這些技術如何改變 urban social life 與 government？

二、會學哪些主題？

  • Smart cities、smart urbanism 與它們形成的 ecosystem。
  • Urban information technologies 的 history 與 frontier。
  • 科技和 urban social life、institutions 的關係。
  • Smart city players、practices、partnerships、strategies 與 policies。
  • Urban infrastructure、data analytics 與城市決策。
  • 城市／地方在 innovation 中扮演的角色。

三、政策、政府與治理

  • 分析 policy frameworks 與 urban innovation tools。
  • 理解政府、企業、研究者、社群與其他城市 actors 如何共同形成 smart-city projects。
  • 討論 smart-city strategies 的機會、挑戰與可能的社會結果。
  • 以 critical perspective 檢查 technology、data 與 governance 之間的權力關係。

四、工具與方法

五、先修與課程位置

  • 官方 restriction：expected to complete CASA0001 Urban Systems Theory。
  • 先理解 urban systems、urban governance 與城市社會科學，會比較容易處理 smart city 的制度與政策問題。
  • 不需要先把某一套 coding software 當成硬性門檻。

六、學完後應該能做到什麼？

  • 解釋 smart city 技術如何嵌入經濟、社會與制度脈絡。
  • 批判性分析 smart-city players、partnerships、policies、infrastructure 與 analytics。
  • 理解城市 innovation 的 policy frameworks 與 practical tools。
  • 評估 smart urbanism 的治理挑戰與社會影響。
  • 把技術方案放回城市、地方與政府的實際 context，而不是只看技術功能。

CASA0011

Agent Based Modelling for Spatial Systems

Term 215 creditsCASA optionalUrban Modelling and SimulationFHEQ Level 7

用 Agent Based Modelling（ABM）建立與評估城市空間中的 agents、規則與互動，從 cellular automata、ODD protocol 到 ABM + GIS，應用在交通、土地使用、行人、危機與基本流行病情境。

Complete module dossier從 individual agents 到 urban simulation
ABM 工作模型主題城市應用工具先備知識學習成果Assessment

一、這門課具體在做什麼？

課程是 hands-on：practicals 會先建立 example models，再逐步把模型改成你自己的 simulation。你會定義 agents、環境、規則與互動，執行 simulation，觀察 aggregate outcomes，並評估模型是否能回答原本的 urban question。

核心不是把 ABM 當成「預測未來的黑盒子」，而是理解 micro-level behaviour 如何產生 macro-level spatial patterns，以及模型假設會如何影響結果。

二、會學哪些 ABM 主題？

  • Cellular automata。
  • ODD protocol：清楚描述 model Overview、Design concepts 與 Details。
  • Competition among agents。
  • Optimisation、forecasts 與 predictions。
  • ABM 與 GIS 的結合。
  • ABM 的 history、current trends 與 model outcomes evaluation。

三、可以拿來模擬哪些城市問題？

  • Pedestrian movement。
  • Traffic／transportation。
  • Land use。
  • Evacuations 與 crises。
  • Basic epidemiology。
  • 其他需要模擬人、車、土地或政策互動的 spatial systems。

四、會使用哪些工具？

  • NetLogo：常見的 agent-based modelling environment。
  • MESA：Python ecosystem 中的 ABM framework。
  • 官方寫法是 NetLogo and/or MESA；實際採用哪一個要以當年度 teaching setup 為準。
  • ABM + GIS 會讓 simulation 的 agents、環境與地理空間位置連起來。

五、先備知識

  • 非程式背景學生官方 strongly advised 先修 CASA0013。
  • 需要能理解基本 programming logic、變數、函式與 model rule。
  • 若要用 MESA，Python 經驗會很有幫助；若使用 NetLogo，仍需要理解 simulation logic。

六、學完後應該能做到什麼？

  • 設計、實作與評估 ABM。
  • 使用 ODD protocol 清楚說明 model design。
  • 把 agents、rules、competition、optimisation 與 forecast 放進 spatial context。
  • 連結 ABM、cellular automata、GIS 與 urban applications。
  • 解釋 individual behaviour 如何形成 aggregate urban pattern。
  • 批判性評估 simulation outcomes 與模型限制。

七、Exam 與 assessment

  • 2026/27 目前列為 50% Coursework + 50% Dissertations, extended projects, and reports，numeric marks。
  • 公開頁面沒有確認各部分是 coding exercise、model report、presentation 或其他固定格式；正式 brief 以 Moodle 與 module team 為準。

官方來源： UCL Module Catalogue：CASA0011

CASA0025

Building Spatial Applications with Big Data

Term 215 creditsCASA optionalBig Data同時列為額外 CASA optionalFHEQ Level 7

從 SQL、spatial database、大型資料處理、web mapping 到 cloud computing，建立能處理大規模空間資料並呈現互動結果的 spatial application。

Complete module dossier把 large spatial data 變成可互動的 web application
課程工作Database 與 SQLWeb 與 cloudGroup project先備知識學習成果Assessment

一、這門課具體在做什麼？

課程處理的是超過一般 local machine compute／storage 能輕鬆處理的 spatial data。你會走完整 cloud geospatial workflow：把資料 import、存進合適的 database、用 SQL／spatial query 分析，再把結果做成 interactive web visualisation 或 spatial application。

重點是從「分析一份資料」走向「設計一個能處理、服務與呈現大型空間資料的系統」。

二、Database、SQL 與空間資料

  • 理解 databases 如何儲存與分析 spatial data。
  • 用 SQL 查詢、篩選、整理與分析大型資料。
  • 處理 spatially enabled data 與空間查詢。
  • PostGIS 可作為 spatial database 的應用脈絡；但目前 UCL module page 公開確認的是 databases、SQL 與 spatial analysis，沒有把某一個 database product 寫成所有學生的硬性 requirement。

三、Web application 與 cloud computing

  • 建立 web-based interaction 與 visualization。
  • 把 spatial analysis 結果放進 interactive map／application。
  • 使用 cloud computing 處理較大的空間資料與分析工作。
  • 理解從資料匯入、分析到互動呈現的全流程，而不只是畫一張靜態地圖。

四、實作與 portfolio

  • 使用 large spatial datasets。
  • 完成 interactive group project，形成可放入 portfolio 的成果。
  • 需要同時考慮資料結構、query、分析、web interaction 與使用者如何理解結果。
  • 這門課適合想把 spatial analysis 延伸成 data product、web map 或 cloud application 的學生。

五、先備知識與課程位置

  • 目前 course page 的 restriction 為 N/A，沒有列出硬性 prerequisite。
  • 現有 programme dependency／課程脈絡把 CASA0013 或 equivalent programming 放在 CASA0025 前面；因此有基本 programming、資料 pipeline 與 spatial data 概念會比較容易。
  • SQL、database 或 web mapping 經驗不是本頁明確列出的硬性門檻，但會降低學習曲線。

六、學完後應該能做到什麼？

  • 設計能儲存與分析 spatial data 的 database。
  • 用 SQL 處理 large spatial datasets。
  • 把 cloud computing 放進 geospatial workflow。
  • 製作 web-based interactive spatial visualisation／application。
  • 把從 import／analysis 到 interactive presentation 的整條 pipeline 做成可展示的 project。

七、Exam 與 assessment

  • 2026/27 目前列為 30% Coursework + 70% Group activity（2 assessments），numeric marks。
  • 公開頁面沒有確認 coursework 或 group activity 的固定格式是否包含 coding、report、demo 或 presentation；正式 brief 以當年度 Moodle 與 module team 為準。

CASA0029

Urban Data Visualisation

Term 215 creditsCASA optionalData VisualisationFHEQ Level 7

以 web-based spatial visualisation 呈現城市與 built environment data：從 interactive mapping、統計與基本 3D visualisation，到 cartography、interaction design 與 group project website。

Complete module dossier把城市 spatial data 做成可互動、可理解的視覺化
課程工作視覺化方法資料類型Workshop 與 project先修學習成果Assessment

一、這門課具體在做什麼？

你會針對 cities／built environment 的問題，選擇資料與視覺化方式，做出 web-based interactive map、統計 visualisation 或 basic 3D visualisation。課程把 GIS data、data science libraries、cartographic design 與 user interaction 接起來，讓圖表不只是裝飾，而是幫助讀者理解研究問題。

二、會學哪些視覺化與設計？

  • Interactive mapping。
  • Statistical visualisation。
  • Basic 3D visualisation。
  • Cartographic design：符號、尺度、色彩與地圖閱讀。
  • Interaction design：決定不同 audience 要能操作到什麼程度。
  • 把 visualization method 和 data／research question 對齊。
  • 以清楚的視覺化傳達 research，而不是只做技術展示。

三、會處理哪些城市資料？

  • Demographic data。
  • Topographic data。
  • Remotely sensed data。
  • Spatio-temporal data。
  • 用這些資料討論 sustainability、equity 與其他 urban challenges。
  • 把 GIS 與 data science libraries 連接起來。

四、Workshop 與 group project

  • Term 2 以 workshops 為主要學習場景。
  • 會完成 group visualisation project，通常呈現為 project website。
  • 課堂會練習資料處理、視覺化、設計與向 audience 說明結果。
  • 官方頁面沒有列出固定 framework／software 名單，因此不把某個 web library 寫成硬性 requirement。

五、先修與課程位置

  • 非程式背景學生官方 strongly advised 先修 CASA0013。
  • 課程 builds on CASA0005 與 CASA0013，因此 GIS、spatial data、Python／data pipeline 基礎會很有幫助。
  • 需要願意處理 data、design、web interaction 與 group collaboration，而不只是做單一統計圖。

六、學完後應該能做到什麼？

  • 選擇適合資料與研究問題的 visualization methods。
  • 製作 interactive maps、statistical visuals 與 basic 3D visuals。
  • 將 cartographic design 與 interaction design 放進 web-based spatial project。
  • 為不同 audience 設計適當的 interaction level。
  • 用清楚的 visualisation 傳達 urban research。
  • 在團隊中完成可展示的 project website。

七、Exam 與 assessment

  • 2026/27 目前列為 30% Coursework + 70% Group activity，numeric marks。
  • 公開頁面提到 group visualization project／通常為 project website，但沒有完整公開每一項的 submission specification、presentation 或 demo 規則。

CASA0028

Designing Spatial Data Stories

Term 215 creditsCASA optionalData VisualisationFHEQ Level 7

用現代 web development、data visualisation libraries 與 LLM／Generative AI 做 interactive spatial data stories，研究互動、敘事、設計選擇與資料如何影響理解。

Complete module dossier用 web technology 設計 spatial data narrative
課程工作技術 stack敘事與設計課堂流程先備知識學習成果Assessment

一、這門課具體在做什麼？

你會把 spatial data 做成一個 interactive data story：決定資料如何被選擇、排序、視覺化、敘事與互動，讓讀者沿著你的設計理解一個城市或空間問題。課程同時要求你思考 visualisation 如何 shape people’s interpretation，以及 design choices 如何支持一個 argument。

二、會使用哪些 web 與 visualisation technology？

  • React／NextJS：建立 modern web UI 與 application structure。
  • Firebase：支援 web project 的資料／服務脈絡。
  • MapLibre：建立互動式地圖。
  • Deck.gl：處理較進階的 spatial／visual layers。
  • Visx：製作可整合進 web UI 的視覺化。
  • 課程也提到 Recharts、MapComponents、frontend environment 與 modern UI libraries。
  • LLM／GitHub Copilot 用於 prototyping 與 scaffold，但要同時理解其 limitations、ethics 與需要人工判斷的地方。

三、空間敘事與社會設計問題

  • Data in Action、State／Society 與 user。
  • Design justice、disclosure／hiding 與 user-centred design。
  • Visual storytelling 與 speculative design。
  • 資料如何被 operationalised，以及誰能看見、誰被隱藏、誰被代表。
  • 使用 OSM、UK Census、history／heritage、art、literature、ecology、architecture 等 spatial datasets。

四、課堂流程與實作

  • 10 次 weekly 1-hour lectures + 2-hour practical workshops。
  • Weeks 1–5：frontend environment、React anatomy、Copilot bootstrapping、VisX／Recharts、MapComponents。
  • Weeks 5–10：group websites 與 design brief。
  • 實作會把 technical build、visual sequencing、timing、interaction 與 sociological／design research 放在一起。

五、先備知識

  • 需要一些 programming experience，至少理解 variables、data types 與 functions。
  • JavaScript／HTML 經驗是 advantage，但不是頁面列出的絕對 prerequisite。
  • 官方建議使用 VS Code。
  • 如果完全沒有 web development，前期需要額外時間熟悉 frontend environment 與 React。

六、學完後應該能做到什麼？

  • 製作 interactive spatial visualisation website。
  • 說明 web app 如何透過 sequencing、interaction 與 design 來講故事。
  • 使用 modern visualisation libraries、JS UI library 與 map components。
  • 以 LLM／GenAI 協助 prototype，同時批判性評估它的使用方式與限制。
  • 把 sociological theories、design ethics 與 data interpretation 納入 spatial story。
  • 在團隊中完成 collaborative prototype／website。

七、Exam 與 assessment

  • 2026/27 目前列為 20% Coursework + 80% Group activity，numeric marks。
  • 公開頁面確認 weeks 5–10 會做 group websites／design brief，但沒有完整列出是否另有 presentation、demo 或 individual reflection；正式 brief 以 Moodle 與 module team 為準。

官方來源： UCL Module Catalogue：CASA0028
