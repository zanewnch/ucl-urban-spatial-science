一、這門課具體在問什麼？ 官方課程來源 ↗

課程用 social science 與 urban theory 來理解城市，而不是把城市只當成一組地圖或數據。你會練習把一個城市問題拆成不同尺度的社會、空間、制度與治理關係，再思考這些關係如何形成 urban system，以及如何轉化成有意義的 research inquiry。

它是 programme 的 conceptual foundation，後續的 spatial analysis、urban modelling、smart cities 與 dissertation 都可以回到這裡的系統思考與城市理論。

二、會學哪些城市理論與主題？ 官方課程來源 ↗

  • Urbanisation、城市發展與 urban geography。
  • Systems theory、complexity theory 與城市作為互相連結的系統。
  • Urban form and function：城市形態如何和功能、活動與空間結構連在一起。
  • Mobility、transport 與城市中的流動。
  • Socio-spatial differentiation：不同群體與地區如何產生空間差異。
  • Urban health 與城市環境、社會結果的關聯。
  • Urban planning、urban governance 與制度如何影響城市。
  • Systems thinking、causal diagrams 與其他用來整理城市關係的 analytical tools。

三、會用什麼工具？ 官方課程來源 ↗

這門課的官方定位是理論、概念與社會科學 foundation，module page 沒有列出像 R、Python 或 QGIS 這樣的固定 software requirement。你比較會使用的是 systems thinking、概念框架、causal diagrams、文獻與案例的批判性分析；具體工具依當年度 lectures、readings 與 coursework brief 而定。

五、學完後應該能做到什麼？ 官方課程來源 ↗

一、這門課具體在做什麼？ 官方課程來源 ↗

典型工作流程是：提出 spatial question 或 hypothesis → 找到 ONS、OSM、政府或其他 contemporary datasets → 清理與整理資料 → 對齊空間範圍與座標系統 → 用 R／QGIS 做空間分析 → 製作地圖與統計圖 → 評估 uncertainty、限制與結果是否合理。

公開 practical handbook 特別強調，課程會使用接近真實研究的資料；資料不會永遠是乾淨、可以直接分析的狀態，因此 data wrangling、格式轉換與錯誤排查本身就是課程的一部分。

二、R：主要分析工具 官方課程來源 ↗

  • 讀取、清理、tidy 與整理資料。
  • 處理 vector、raster、point、polygon 等 spatial data。
  • 進行 spatial joins、attribute／geometry 整合、格式轉換與 CRS 處理。
  • 製作統計圖、靜態地圖與具備 cartographic standards 的視覺化。
  • 用 R packages 執行 spatial statistics、pattern analysis 與 regression。
  • 透過 RMarkdown／GitHub 建立較可重現的分析流程。

三、QGIS：基本 GIS 與地圖工作 官方課程來源 ↗

  • 載入、查看與檢查不同空間圖層。
  • 理解 projections、coordinate reference systems 與 spatial extent。
  • 做基本的 spatial filtering、buffer、point-in-polygon 與空間資料整理。
  • 協助檢查資料、操作圖層與輸出地圖。
  • QGIS 是課程的一部分，但官方描述是「basic concepts」；主要分析主軸仍然是 R。

四、Python 可以嗎？ 官方課程來源 ↗

目前 UCL CASA0005 官方頁面與公開 handbook 都把 R 列為主要 data science programming language，並沒有把 Python 列為這門課的主要教學工具。因此 Python 可以作為你自己的輔助工具，但不能自行假設正式 coursework 一定接受 Python 取代 R；實際作業規則要以當年度 Moodle assessment brief 為準。

五、會用到的統計與空間分析 官方課程來源 ↗

  • Descriptive statistics：資料型態、分布、histogram、基本空間資料描述。
  • Point pattern analysis：Kernel Density Estimation、Quadrat Analysis、Ripley’s K。
  • Spatial clustering：DBSCAN 等以空間位置判斷群聚的方法。
  • Spatial autocorrelation：Moran’s I、Geary’s C、Getis-Ord 與 LISA。
  • Spatial operations：areal interpolation、point-in-polygon、buffer、hot-spot analysis。
  • Regression：linear／multiple regression、bootstrap 與 regression assumptions。
  • Spatial regression：spatial lag、spatial error 與 Geographically Weighted Regression（GWR）。

六、學完後應該能做到什麼？ 官方課程來源 ↗

  • 用 QGIS 與 R 支援 GIScience 技術的應用。
  • 按照 cartographic standards 製作合適的地圖。
  • 清理、連接、轉換與管理空間資料。
  • 選擇適合的 spatial analysis 回答不同空間問題。
  • 理解 geographic data 的 representation、uncertainty 與資料品質問題。
  • 批判性地解釋 spatial statistical analysis，而不是只報告一個數字。
  • 比較不同全球 spatial datasets 的優點、限制與適用情境。

七、統計基礎要到什麼程度？ 官方課程來源 ↗

官方沒有要求你入學前已經會 GIS 或 R，但課程進度很快。實際上，先具備基本 descriptive statistics、資料分布、圖表閱讀、相關與 regression 結果解讀會很有幫助；更進階的 spatial statistics 會在課程中逐步建立。

準備方向：不用先把所有 R syntax 或 QGIS 工具背熟，但最好先理解平均數、變異、分布、correlation、regression 的基本概念，以及「空間上相鄰的資料可能不是獨立的」這個核心問題。

逐週上課內容與進度（公開 2025/26 教材地圖） 官方課程來源 ↗

每週包含一堂 lecture 和一堂 practical。下面把公開 weekly notes 的學習目標轉成「課堂會理解什麼、Notebook 要實際做什麼、最後要能說明什麼」；實際投影片、資料集和練習題以 2026/27 Moodle 為準。公開課程頁明確列出 2026/27 是 10+10 次課，並把本年度內容註明為依 2025/26、可能變動。

第 1 週｜探索性資料分析 I：資料型態與描述統計 官方課程來源 ↗

Lecture：分辨類別、順序、連續等資料型態；理解平均數、中位數、四分位距、標準差等摘要指標各自回答什麼問題，以及單看平均值為何會隱藏分布差異。

Practical：在 Notebook 載入表格、檢查欄位型態與缺值，計算摘要統計，畫直方圖和箱型圖；比較城市／區域分組後分布是否不同，辨認偏態和離群值。

本週產出：一張有標題與單位的箱型圖，以及一段用中位數和四分位距描述城市指標分布的文字。

本週公開教材 ↗

第 2 週｜探索性資料分析 II：機率、分布與資料偏差 官方課程來源 ↗

Lecture：認識常見機率分布的形狀和特性，理解抽樣／代表性問題，以及指數、對數在資料尺度轉換中的用途。

Practical：用圖表比較偏態資料與較對稱分布；練習指數與對數轉換前後的尺度；檢查一份樣本和目標人口在關鍵特徵上是否不同，討論這會如何影響城市研究結論。

本週產出：一張分布比較圖，以及「樣本代表誰、可能漏掉誰」的偏差檢查說明。

本週公開教材 ↗

第 3 週｜假設檢定：把研究問題變成可檢查的證據 官方課程來源 ↗

Lecture：從研究問題寫出虛無假設與對立假設；理解抽樣變異、p 值、顯著水準，以及第一類錯誤（誤報）和第二類錯誤（漏報）。練習判斷應使用哪類檢定，而不是只背顯著與否。

Practical：在 Python 對一個城市指標提出比較問題，執行相應的統計檢定，讀取統計量和 p 值；把數值結果翻譯成一般讀者聽得懂的句子，並寫出不能由此推論的事。

本週產出：一份含 H₀/H₁、檢定選擇、結果與限制的短結論。

本週公開教材 ↗

第 4 週｜線性代數入門：函數、向量與矩陣 官方課程來源 ↗

Lecture：讀懂簡單數學符號和線性方程；把一組變數看成向量、把多筆觀測看成矩陣，理解矩陣運算如何成為迴歸和多變量方法的計算骨架。

Practical：用 NumPy 建立小型向量和矩陣、做基本運算，將一個簡單線性關係寫成矩陣形式，檢查維度是否相容；重點是理解資料如何進模型，不要求手算大型矩陣。

本週產出：把一個簡單表格表示為向量／矩陣，並說明每一列和每一欄代表什麼。

本週公開教材 ↗

第 5 週｜衡量變數關係：共變、相關與 ANOVA 官方課程來源 ↗

Lecture：區分共變與相關；比較 Pearson（線性關係）和 Spearman（排序／單調關係）；學會相關不代表因果。認識 ANOVA 如何比較多組平均數及其基本解讀。

Practical：畫散佈圖後計算 Pearson/Spearman 相關，比較離群值或非線性如何影響係數；用分組圖和 ANOVA 檢視多個區域群組的指標差異，將圖、檢定和研究問題放在一起解讀。

本週產出：相關散佈圖、係數解讀，以及一段謹慎區分「一起變動」和「造成影響」的結論。

本週公開教材 ↗

第 6 週｜簡單線性迴歸：建立第一個解釋模型 官方課程來源 ↗

Lecture：以一個連續解釋變數預測／描述一個連續結果，理解截距、斜率、殘差、自由度、p 值和 R²。先看資料與模型圖，再讀輸出；不把 p 值或 R² 單獨當作模型好壞判準。

Practical：先畫散佈圖，再以 OLS 配適迴歸線；讀取係數、信賴／不確定性資訊和 R²，檢視殘差，找出外推風險及樣本代表性問題。

本週產出：一個回歸圖和一段係數解釋（自變數增加一單位時，預期結果平均如何改變），再補上模型限制。

本週公開教材 ↗

第 7 週｜多元迴歸：控制變數、類別變數與交互作用 官方課程來源 ↗

Lecture：加入多個連續／類別解釋變數，理解 dummy coding、控制其他條件後的係數、混雜因素和交互作用；辨認多重共線性。城市資料有空間或時間自相關時，殘差可能違反獨立假設。

Practical：建立由簡到繁的 OLS 模型，比較加入人口／地區等控制變數前後係數如何改變；檢查共線性和殘差空間／時間型態；嘗試交互作用項，觀察一個變數的關係是否隨另一變數改變。

本週產出：模型比較表，清楚指出哪些係數改變、可能的混雜因素及仍未解決的空間依賴。

本週公開教材 ↗

第 8 週｜多層次迴歸：處理巢狀與群聚資料 官方課程來源 ↗

Lecture：用個體位於 neighbourhood、學校位於 local authority 等例子理解層級結構；區分 fixed effects 與 random effects；認識 null model、variance components、ICC（組內相關）和 shrinkage。

Practical：先以空模型拆解個體層與群組層變異，再比較一般 OLS 和 mixed-effects model；練習設定隨機截距（必要時看隨機斜率）並解讀模型輸出。教材示範 Python/R 類似語法的模型讀法。

本週產出：一段說明群組差異有多大、ICC 是否支持多層次模型，以及 random intercept 如何解讀的結果摘要。

本週公開教材 ↗

第 9 週｜降維：主成分分析（PCA） 官方課程來源 ↗

Lecture：理解降維是把多個彼此相關的指標濃縮成較少維度；認識 PCA、主成分、解釋變異量，以及結果可視化和解讀時的界線。

Practical：選取多個城市指標、處理尺度差異（標準化）、執行 PCA，畫解釋變異圖與前兩個主成分散佈圖；查看各變數載荷，判斷哪些指標共同構成某一主成分。

本週產出：一張 PCA 圖和一段解釋保留了多少變異、主成分可能代表什麼，以及降維丟失了什麼資訊。

本週公開教材 ↗

第 10 週｜分群：找出相似觀測的群組 官方課程來源 ↗

Lecture：理解 clustering 是無監督探索；比較 K-means 和階層式分群的基本邏輯，討論距離、尺度、群數選擇及群組解讀，不把演算法產生的群組直接當成客觀存在的類別。

Practical：標準化多項區域指標，試跑 K-means 與階層式分群；比較不同群數的分配，用圖表呈現結果，再回看群組的特徵差別和方法敏感度。

本週產出：一張分群視覺化和一份群組摘要，說明群數選擇、各群特徵與分類不確定性。

本週公開教材 ↗

Python 環境設置：以 CASA Computing Platform 為主 官方課程來源 ↗

CASA0007 公開教材要求使用 CASA Computing Environment；它推薦 Podman container，讓全班 Python 與函式庫版本一致。不要先自行 pip 安裝一堆套件，以免和課程 container 發生版本衝突。以下是 Windows 的可操作路徑；Mac/Linux 請依同一官方安裝頁切換作業系統指示。

開始前：檢查電腦 官方課程來源 ↗

  • 官方健康檢查的基本門檻：至少 16GB RAM、超過 30GB 可用空間；Windows 10 Home 是常見虛擬化問題來源。較新年度教材曾建議預留更多空間，先確認 CASA setup health check。
  • Windows 開啟 Start，搜尋「Turn Windows features on or off」，啟用 Virtual Machine Platform 和 Windows Hypervisor Platform，重新開機。另依 UCL 指引安裝 WSL2；若校務 IT 管理此電腦，先確認校方政策。

安裝所需程式 官方課程來源 ↗

  1. 安裝 Windows Terminal、Podman Desktop、Git 和 GitHub Desktop。GitHub Desktop 設定用於課程的 GitHub 帳號。
  2. 啟動 Podman Desktop，完成初始設定；開啟新的 Windows Terminal（PowerShell 分頁）。
  3. 建立並啟動 Podman 虛擬機器，然後拉取一個測試 image：
podman machine init
podman machine start
podman run hello-world

看到 Hello Podman World 即通過 Podman 基本測試。若 machine 已建立，第二次開始只需 podman machine start。

  1. 先建立一個專門放 CASA0007 notebooks 的資料夾，在 Windows Terminal 用 cd 進入該資料夾；container 會把目前資料夾掛載成 notebook 工作目錄。
  2. 以下是公開 CASA Computing Platform 指引中的 x64/AMD64 範例命令（整行貼進 PowerShell）。它會下載約數 GB 的課程 image，首次啟動需等候：

常見卡點 官方課程來源 ↗

  • podman machine start 無法啟動：先確認兩個 Windows virtualization feature 已啟用並重新開機；依 CASA platform common problems 檢查 WSL2／BIOS virtualization。若提示 machine configuration/permission 錯誤，先看錯誤訊息再依官方指南重建命名 machine。
  • podman: command not found：完全關閉並重新開啟 Terminal，確認 Podman Desktop 已安裝並啟動。
  • 瀏覽器連不到 8888：確認 podman ps 有 sds2025，且啟動命令中的 port mapping 是 -p 8888:8888。
  • Notebook 找不到套件：確認 kernel 是 container 內的 Python 3；先別任意切換本機 Python，並對照 Moodle 的當年 setup 指示。

一、這門課具體在做什麼？ 官方課程來源 ↗

你會從城市或空間資料開始，先描述資料的型態與分布，再選擇合適的統計工具，建立模型、檢查關係，最後把模型結果轉化成可以解釋的 spatial／urban insight。它不是只背公式，而是訓練你判斷「這份資料適合怎麼分析」以及「分析結果能不能支持原本的研究問題」。

官方明確說明這是一門介紹 statistical and mathematical tools 的碩士課程，目標是建立概念理解，而不是要求非常進階的 technical mathematics；官方也表示不假設學生已有大量先備知識。

二、會學到哪些統計與數學方法？ 官方課程來源 ↗

  • Data description and representation：理解資料如何被整理、描述與呈現。
  • Probability distributions：用機率分布理解不確定性與資料可能的生成型態。
  • Hypothesis testing：把研究問題轉成可檢驗的統計問題，理解檢定與結果解讀。
  • Linear algebra：建立後續模型與多變量分析需要的矩陣／向量概念。
  • Measuring relationships：衡量變數之間的關係，並判斷關係的強弱與限制。
  • Regression：用迴歸建立解釋或預測模型。
  • Multiple regression：同時處理多個解釋變數，理解控制其他因素後的關係。
  • Multilevel regression：處理具有層級結構的資料，例如個體位於 neighbourhood、neighbourhood 位於城市。
  • Dimensionality reduction：把複雜、多變量資料轉成較容易理解的低維結構。
  • Clustering：依資料特徵找出群組或型態，不預先假定每筆資料屬於哪一群。

CASA0013 Python 環境：Podman container + JupyterLab

可以把 Podman 想成用來啟動課程 Docker 式 container 的工具：container 內已準備 Python 和課程套件；JupyterLab 則是在瀏覽器中開 notebook 的介面。依 CASA Computing Platform 最新安裝頁，Windows 使用 Podman Desktop、Windows Terminal、Git/GitHub Desktop，並啟動 sds2026 image。這裡先列 Windows 10/11 的完整做法；Mac、Apple Silicon 和其他系統請依同一份官方安裝頁選對應指令。課程以 JupyterLab/container 執行 notebook，官方 setup 沒有指定 VS Code。

展開 Windows 安裝步驟（Podman → 課程 container → JupyterLab）
  1. 先檢查電腦規格。到 Windows「設定 → 系統 → 關於」確認 System type 是 x64-based processor（AMD/Intel）或 ARM-based processor；CASA 建議至少 16 GB RAM、30 GB 可用空間。官方硬體與系統健康檢查 ↗
  2. 開啟 Windows 虛擬化功能。按 Start 搜尋「Turn Windows features on or off」，勾選 Virtual Machine Platform 和 Windows Hypervisor Platform，套用後重新開機。CASA Windows 虛擬化設定 ↗
  3. 安裝 WSL2。以系統管理員身分開啟 PowerShell，執行以下指令；依畫面提示完成，若要求重開機就先重開。Windows 通常會一併安裝預設 Ubuntu 發行版；本課的 Python 仍在 Podman container 裡執行。
    wsl --install
    安裝方法見 Microsoft WSL 安裝說明 ↗及 CASA WSL2 指引 ↗。
  4. 安裝課程基本工具。安裝 Windows Terminal、Podman Desktop、Git for Windows 和 GitHub Desktop。GitHub Desktop 請以 UCL email 綁定課程 GitHub 帳號。安裝清單和步驟見CASA 官方安裝頁 ↗
  5. 重新開啟終端機並啟動 Podman。安裝完成後關閉舊的 Windows Terminal，再開一個新的 PowerShell 分頁；啟動 Podman Desktop，等它完成初始設定並顯示 engine 可用。官方提醒舊終端機可能還找不到剛安裝的 podman 指令。
  6. 建立 Podman 虛擬機。在新的 PowerShell 分別執行以下兩行。--rootful 是 CASA 本年度指引要求的設定，不要省略。
    podman machine init --memory 4092 --rootful
podman machine start
    如果回報 machine 已存在，不要重複 init，改執行 podman machine start。官方 Podman machine 設定 ↗
  7. 先測試 Podman 本身。
    podman run hello-world
    第一次執行會下載測試 image；看到 Hello Podman World 表示 Podman 可以下載並執行 container。若失敗，先看CASA 安裝問題指南 ↗。
  8. 建立本機課程資料夾。在 PowerShell 執行以下兩行。Notebook 會存在這個 Windows 資料夾，即使停止或移除 container 也會保留。
    New-Item -ItemType Directory -Force -Path "$HOME\CASA0013"
Set-Location "$HOME\CASA0013"
    確認目前位置是該資料夾：
    Get-Location
  9. 啟動 CASA 課程環境。先確認「設定 → 系統 → 關於」的 System type：AMD/Intel x64 用 sds:2026-amd64；ARM Windows 用 sds:2026-arm64。下列指令是 x64 Windows 的 PowerShell 版本，請整行貼上執行（不要在 Command Prompt／cmd 執行）。官方 image 約 1–5 GB，第一次下載需要一些時間。
    podman run --rm -d --name sds2026 -p 8888:8888 -p 4444:4444 -v "${PWD}:/home/jovyan/work" docker.io/jreades/sds:2026-amd64 start.sh jupyter lab --NotebookApp.notebook_dir=/home/jovyan/work --LabApp.password='' --ServerApp.password='' --NotebookApp.token=''
    若你的 Windows 是 ARM 架構，把命令中的 sds:2026-amd64 換成 sds:2026-arm64。來源：官方 sds2026 image 與啟動參數 ↗
  10. 在瀏覽器開啟 JupyterLab。前一步成功後前往 http://localhost:8888。新增 Python 3 notebook，在第一格輸入並按 Run：
    import sys
import pandas as pd
import geopandas as gpd

print(sys.version)
print("pandas", pd.__version__)
print("GeoPandas", gpd.__version__)
    若看到 Python、pandas、GeoPandas 版本而沒有錯誤，代表課程 Python kernel 已啟動。
  11. 確認檔案會留在電腦。在 notebook 建立並儲存測試檔後，回到 $HOME\CASA0013 檢查檔案；container 的 /home/jovyan/work 已對應到這個本機資料夾。--rm 只會在 container 停止時移除 container，不會刪除掛載資料夾或已下載的 image。
  12. 結束與下次啟動。用完在 PowerShell 執行 podman stop sds2026。下次開課先啟動 Podman Desktop，再執行 podman machine start，然後回到 $HOME\CASA0013 重跑第 9 步的 container 指令，最後開啟 http://localhost:8888。若只是關閉瀏覽器，container 仍在執行；要停止它才會釋放資源。

常見狀況與檢查

  • podman 找不到：安裝後重新開啟 Windows Terminal，並確認 Podman Desktop 已啟動。
  • Podman machine 無法啟動：確認 WSL2 已安裝、兩個 Windows 虛擬化功能已開啟並重開機；對照 CASA Common Problems ↗。
  • 8888 網頁打不開：執行 podman ps 確認 sds2026 正在執行；再執行 podman logs sds2026 查看啟動訊息，並確認網址是 http://localhost:8888。
  • Notebook 找不到檔案：在 JupyterLab 左側檔案列表確認位於 work；PowerShell 的目前資料夾要是 $HOME\CASA0013 才啟動 container。

一、這門課具體在做什麼？ CASA0013 公開課本 ↗

你會練習一個 end-to-end spatial data science pipeline：取得或讀入資料、清理與整理、用 geographic／quantitative／textual lenses 探索、做視覺化、解讀結果，再把結果清楚地呈現給別人。官方說明它補足 CASA0007 與 CASA0005，把統計、地理與計算概念放進同一個實作流程。

官方也以真實問題與資料作為脈絡，例如 Airbnb／London 類型的城市資料問題；它不是只教 Python syntax，而是把程式能力、資料判斷、批判性思考與 communication 放在一起。

二、Python 會學什麼？ CASA0013 公開課本 ↗

  • Variables、lists、dictionaries 等基本資料結構。
  • Functions、libraries、methods 與 classes。
  • 用 Python 處理 large real-world data。
  • 以 numeric、spatial 與 textual perspectives 看資料。
  • 從 computational notebooks 逐步建立可讀、可重現的分析。

三、技術實務、reproducibility 與倫理 CASA0013 公開課本 ↗

  • 用 command line、Docker／Podman、Git／GitHub 與 Quarto 建立較可重現的工作流程。
  • 討論資料選擇、呈現方式、解讀與 communication，而不是只追求圖表好看。
  • 理解 spatial data science 的 technical practices 以及更廣泛的 ethics。
  • 重點包含如何把結果呈現給不同讀者，以及資料與分析如何影響他人對城市的理解。
