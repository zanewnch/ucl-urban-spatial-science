# Repository instructions

## Commit and push after changes

- After completing any requested work that changes files in this repository, immediately commit the changes for that work and push the commit to the current branch's upstream. Apply this to changes of any size, including code, documentation, configuration, and assets.
- Finish the requested change and any needed validation before committing; do not leave completed work waiting for a separate commit or push request.
- Stage only files changed for the current work. Preserve and exclude unrelated changes that were already present.
- Use a concise Conventional Commit message, preferably in Traditional Chinese.
- Before committing, review the staged diff and run `git diff --cached --check`. After pushing, confirm the branch is up to date with its upstream and report the commit hash.
- For read-only work that changes no repository files, do not create an empty commit.
- If pushing fails or the branch has no usable upstream, report the exact blocker. Do not force-push or rewrite remote history.

## Project scope and source-backed content

- This repository is a static, dependency-free 2026–27 UCL CASA Urban Spatial Science MSc overview; the public output is the [`site/` directory](https://github.com/zanewnch/ucl-urban-spatial-science/tree/main/site), and the project summary identifies the [published GitHub Pages site](https://zanewnch.github.io/ucl-urban-spatial-science/) and [alternate source page](https://ucl-urban-spatial-science.zanewnch.chatgpt.site/urban-spatial-science). See the [README](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/README.md).
- [`site/index.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/index.html) is the programme overview, year map, credit summary, Welcome Week information, and source index; [`site/term1.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/term1.html) covers Term 1 modules and study resources; [`site/term2.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/term2.html) covers the dissertation, pathways, dependencies, and elective details; [`site/notes.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/notes.html) contains the supplementary notes area; [`site/change-log.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/change-log.html) records project changes.
- The programme summary states 180 credits overall: 45 credits across three taught compulsory modules, 60 credits for CASA0010 Dissertation, and 75 elective credits. The authoritative programme structure is the [UCL Urban Spatial Science MSc page](https://www.ucl.ac.uk/prospective-students/graduate/taught-degrees/urban-spatial-science-msc); the summary and module-by-module explanation are linked from the [homepage](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/index.html).
- The 2026–27 welcome material describes pathway modules as recommended thematic choices; students should verify module availability and selection rules with the [UCL programme page](https://www.ucl.ac.uk/prospective-students/graduate/taught-degrees/urban-spatial-science-msc) and [CASA Welcome Sway](https://sway.cloud.microsoft/nDoVumNgOh4tpubH?ref=Link). Do not present pathways as fixed exclusive tracks or promise a universal credit allocation without a current official source.
- Module descriptions, prerequisites, assessment, teaching weeks, and reading/resource summaries are year-specific. Link each claim to the matching [UCL Module Catalogue entry](https://www.ucl.ac.uk/module-catalogue/) or the relevant course materials; Term 1 source links are collected in [`site/term1.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/term1.html), while Term 2 and pathway source links are in [`site/term2.html`](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/term2.html). Use the [CASA Welcome Sway](https://sway.cloud.microsoft/nDoVumNgOh4tpubH?ref=Link) for 2026–27 welcome, dates, contacts, and pathway guidance.
- Treat UCL catalogue and programme information as authoritative for formal requirements; identify interpretations, study advice, and thematic summaries as editorial guidance. When the official source is silent, say so and do not turn an inference into a requirement. The project’s cited-source overview is in the [homepage source section](https://github.com/zanewnch/ucl-urban-spatial-science/blob/main/site/index.html#sources).
- Every newly added or materially updated factual claim, statistic, date, module detail, external resource, or recommendation must include a nearby clickable link to the exact supporting source. Prefer primary UCL sources; for a practical, reading, or tool instruction, link its original resource. If the source cannot be verified or does not support the claim, omit the claim or label the uncertainty and link the nearest relevant source. Existing in-page source links should be retained when editing content.
