展開 Week 1 內容

Lecture：用英格蘭學校表現資料學會描述資料 原始投影片 ↗

  • 觀測單位和研究變數：使用英格蘭教育部（DfE）2022/23 學校表現資料；每列代表一所學校，而不是一名學生。介紹 Attainment 8 學校平均分，以及它沒有調整學校收生組成這項限制。資料集與觀測單位投影片 ↗
  • 資料尺度與欄位型態：區分 nominal、ordinal、interval、ratio 四種測量尺度，並介紹 binary、categorical、count、real-valued 等統計型態。數值編碼不會自動把類別或順序欄位變成連續數值；Progress 8 的 0 代表平均預期進步，因此不能把正負數當作倍數比較。測量尺度投影片 ↗ 數值編碼警示 ↗
  • 分布、中間位置與離散程度：以直方圖看完整分布形狀，以 boxplot 摘要中位數、四分位數與離群值；也比較 violin plot 等呈現方式。Mean、median、mode、range 和 standard deviation 各有用途，摘要前應先看分布；只報平均數、不報 spread，可能掩蓋學校之間很大的差異。摘要指標 ↗ 直方圖與頻率分布 ↗ Boxplot ↗
  • 計數、比例與標準化：大校通常有較大的人數計數，因此比較時可能要看具明確分母的比例／率；不同單位的變數可用 z-score（離平均幾個標準差）轉到共同尺度。後續 PCA 和 clustering 會用到標準化。計數、率與分母 ↗ Z-score ↗
  • 缺漏與離群：辨認 DfE 的 SUPP、NP、NE、LOWCOV、NEW 等狀態；部分缺漏與小型學校或資料適用範圍有關，不一定是隨機缺漏。離群值可能是錯誤、特殊但真實的情況，或值得研究的案例；投影片介紹 z-score 與 Tukey fences 等判定規則，並強調說明採用的規則及處理理由。Null values ↗ Outliers ↗ 離群值判定 ↗

Practical：在 R 或 Python 中重做描述與視覺化 原始 Practical ↗ · Notebook ↗

Practical 明確說明範例同時提供 R 與 Python，學生可擇一。任務包括讀取並合併 DfE 資料、正確處理 suppression codes、判斷欄位型態、描述和繪製變數、依自選分組欄位比較學校、檢查缺漏與離群，並寫出資料能支持及不能支持的主張。準備說明 ↗ Task 1 ↗ Task 6：分組 boxplot／violin ↗ Task 7：寫下可支持的解讀 ↗
