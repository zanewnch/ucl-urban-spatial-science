一、這門課具體在做什麼？ 官方課程來源 ↗

你會針對 cities／built environment 的問題，選擇資料與視覺化方式，做出 web-based interactive map、統計 visualisation 或 basic 3D visualisation。課程把 GIS data、data science libraries、cartographic design 與 user interaction 接起來，讓圖表不只是裝飾，而是幫助讀者理解研究問題。

二、會學哪些視覺化與設計？ 官方課程來源 ↗

  • Interactive mapping。
  • Statistical visualisation。
  • Basic 3D visualisation。
  • Cartographic design：符號、尺度、色彩與地圖閱讀。
  • Interaction design：決定不同 audience 要能操作到什麼程度。
  • 把 visualization method 和 data／research question 對齊。
  • 以清楚的視覺化傳達 research，而不是只做技術展示。

三、會處理哪些城市資料？ 官方課程來源 ↗

  • Demographic data。
  • Topographic data。
  • Remotely sensed data。
  • Spatio-temporal data。
  • 用這些資料討論 sustainability、equity 與其他 urban challenges。
  • 把 GIS 與 data science libraries 連接起來。

四、Workshop 與 group project 官方課程來源 ↗

  • Term 2 以 workshops 為主要學習場景。
  • 會完成 group visualisation project，通常呈現為 project website。
  • 課堂會練習資料處理、視覺化、設計與向 audience 說明結果。
  • 官方頁面沒有列出固定 framework／software 名單，因此不把某個 web library 寫成硬性 requirement。

五、先修與課程位置 官方課程來源 ↗

  • 非程式背景學生官方 strongly advised 先修 CASA0013。
  • 課程 builds on CASA0005 與 CASA0013，因此 GIS、spatial data、Python／data pipeline 基礎會很有幫助。
  • 需要願意處理 data、design、web interaction 與 group collaboration，而不只是做單一統計圖。

六、學完後應該能做到什麼？ 官方課程來源 ↗

  • 選擇適合資料與研究問題的 visualization methods。
  • 製作 interactive maps、statistical visuals 與 basic 3D visuals。
  • 將 cartographic design 與 interaction design 放進 web-based spatial project。
  • 為不同 audience 設計適當的 interaction level。
  • 用清楚的 visualisation 傳達 urban research。
  • 在團隊中完成可展示的 project website。

七、Exam 與 assessment 官方課程來源 ↗

  • 2026/27 目前列為 30% Coursework + 70% Group activity，numeric marks。
  • 公開頁面提到 group visualization project／通常為 project website，但沒有完整公開每一項的 submission specification、presentation 或 demo 規則。
