Week 01 · 2026-10-08

從資料到第一張地圖

Lecture: Introduction to GIS
Practical: Geographic Information: The Basics
Presenter: Andy MacLachlan

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • GIS 把位置、幾何與屬性放在一起；GIScience 進一步追問資料如何代表真實世界。先知道一列資料代表一個 borough、一個事件或一個格網，才能決定如何合併與分析。
  • Vector 以點、線、面表示離散物件；raster 以格網表示數值。CSV 只有表格，不會自動具有幾何。資料有地區代碼，也仍需對應邊界才能畫出行政區地圖。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

先能辨識檔案副檔名與資料夾。下載前記錄資料的日期、地理範圍、欄位單位及授權，保留原始檔，避免一開始就覆寫。

來源與延伸：公開教材章節 ↗

教材、資料與工具

目前公開章節用 London borough 邊界與 fly-tipping CSV 示範屬性合併；實際資料連結及檔案位置依章節。QGIS 可輔助檢視圖層，R 用來記錄可重跑流程。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 先解壓縮邊界資料，確認讀的是 borough layer；若用 Shapefile，保留同名的配套檔，不只移動 .shp。
  2. 在 RStudio 開啟課程 project，確認 working directory，讀入邊界與 CSV；先看欄位名稱、列數及資料型態，再畫簡單邊界圖。
  3. 找出兩份資料共同的地區識別碼，檢查空值、重複值與字串格式。不要先用名字猜配對，因為拼字差異不等於不同地區。
  4. 先選定要用的年度和欄位，再做 attribute join；比較合併前後列數，列出未配對區域，確認沒有因重複 key 把一個面複製多次。
  5. 畫出數值分布並匯出結果；寫清楚事件件數的時間範圍，不能把空值自動當零，也不能把件數直接當成每人發生率。

來源與延伸：公開教材章節 ↗

成果如何解讀？

地圖是資料與邊界的共同產物。空白區域可能是未配對或無資料，不一定是沒有事件。第一週的成功標準是配對可核對、位置合理、單位可解釋。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • 讀不到檔案：檢查解壓縮後的實際位置與檔名大小寫；不要照抄教材作者電腦的絕對路徑。
  • 合併後一片 NA：檢查 key 類型、年度、空白字元及行政區版本；先列 unmatched keys 再改資料。

能指著一個面說明它的識別碼、資料年度與數值單位嗎？能證明每個 borough 最終只有一列嗎？

來源與延伸：公開教材章節 ↗

建議保留的成果（非新增作業）

一張基礎地圖、原始資料來源表、合併檢查紀錄與可重跑 R script。

來源與延伸：公開教材章節 ↗

Week 02 · 2026-10-15

用 R 整理資料與表達流程

Lecture: Geospatial Information Systems
Practical: Introduction to R
Presenter: Claire Dooley

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • R 的 object、function、vector 與 data frame 是基礎。函式的輸入、參數和回傳值要能分開讀；程式跑過一次不代表資料型態或操作順序正確。
  • filter 選列、select 選欄、group_by 加 summarise 做分組統計；join 是配對兩份資料。先把問題寫成「依何種單位、選哪些觀察、算什麼量」，再選函式。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

重跑 Week 1 的讀檔與合併。把不知道的 R 指令記到問題清單，學會用 ?函式名稱查說明；練習從 script 執行，不只在 Console 留下零散命令。

來源與延伸：公開教材章節 ↗

教材、資料與工具

教材涵蓋 CSV 清理、data frame 操作、spatial data、簡單製圖及 tidy data；使用 RStudio、dplyr／tidyverse、sf 與章節指定的製圖工具。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 建立小型練習表，檢查 numeric、character 與 NA；用 names、str 和 head 觀察結構，避免直接對整份資料做不可追蹤的轉換。
  2. 讀入 CSV，辨識標題列、空白列及混合格式欄位；把清理動作存成程式，保留原始讀取物件供比較。
  3. 依資料定義篩選年份或類別，選欄、改名與建立新變數。每一步查看列數，確認沒有因條件或缺值把需要的資料丟掉。
  4. 分組計算摘要時明說分母。比較「各組百分比的平均」與「先加總分子分母再算比例」，不要把兩者視為同一估計。
  5. 將整理後表格 join 到幾何，做一張地圖與一張非空間圖，檢查相同變數在兩種表達下是否一致。

來源與延伸：公開教材章節 ↗

成果如何解讀？

資料清理是有理由的轉換，不是讓錯誤訊息消失。可以用少量資料手算預期值，確認程式做的事情與研究問題一致。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • object not found：檢查是否先跑建立物件的 chunk、是否拼錯大小寫；從乾淨 session 重跑能揭露隱藏依賴。
  • 數字欄位變文字或多出 NA：先查原始值中的符號和缺值編碼，再選擇轉換方法。

能解釋一條資料管線每一步的輸入與輸出嗎？能說明 group_by 後一列結果代表哪個群組嗎？

來源與延伸：公開教材章節 ↗

建議保留的成果（非新增作業）

一份有註解的清理 script、一個摘要表、一張圖及一段資料清理理由。

Week 03 · 2026-10-22

投影、raster 與描述統計

Lecture: Representing the World: From infinitely complex reality to models and representations
Practical: Spatial descriptive statistics
Presenter: Andy MacLachlan

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • CRS 定義座標如何對應地球；地理座標的角度不等於公尺。指定 CRS 是補上座標的解釋，transform 是把位置轉到另一個參考系統，兩者不能交換。
  • Raster resolution 決定格網尺度，取樣點得到的是格網支持範圍內的資料值。平均、標準差、分位數和 histogram 描述分布的不同面向。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

複習 vector／raster 及欄位型態，能解釋 mean 和 median 的差別。確認下載空間 raster 的儲存空間，先閱讀資料產品的單位與時間範圍。

來源與延伸：公開教材章節 ↗

教材、資料與工具

公開章節使用 WorldClim raster、城市／位置資料，依序處理投影、載入 raster、取值與 histogram；實際解析度、檔案及套件依章節。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 載入一份 vector 和 raster，列出兩者 CRS、extent、單位與解析度；先畫圖看位置是否合理。
  2. 依分析目的選擇參考系統，必要時真正轉換座標；不要只把 EPSG 標籤換成想要的值。
  3. 讀入所需 raster layer，確認變數、月份或年度，避免將不同 layer 當成同一時間的觀測。
  4. 在指定位置抽取格網值，檢查 NA 是否來自超出 extent 或缺值；選幾個位置回到地圖核對。
  5. 計算摘要與 histogram，記錄 bins、有效樣本數及單位；比較位置樣本的分布，不把抽樣城市當成全世界面積的分布。

來源與延伸：公開教材章節 ↗

成果如何解讀？

相同地點在不同解析度下可能得到不同值。呈現結果時應說明資料支持尺度與抽樣方式，不能把地圖上細密的點視為量測精度。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • 圖層對不上：檢查 datum、CRS 與原始座標單位；st_set_crs 不能修正原本屬於另一套座標的數字。
  • 摘要受極端值支配：同時看 histogram、分位數與缺值，調查資料定義後再決定是否排除。

能說明一次 raster extraction 的空間與時間意義嗎？能區分重投影、改標籤與 resampling 嗎？

來源與延伸：公開教材章節 ↗

建議保留的成果（非新增作業）

CRS／解析度紀錄、抽取值表、histogram 與一段尺度及抽樣限制。

來源與延伸：公開教材章節 ↗

Week 04 · 2026-10-29

把分析變成可重現的報告

Lecture: GI Science and Reproducible Research
Practical: Git, GitHub and RMarkdown
Presenter: Andy MacLachlan

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • Git 追蹤本機檔案版本；GitHub 提供遠端 repository。commit 是可識別的版本，push／pull 在本機與遠端間同步，不會替你驗證統計方法。
  • RMarkdown 把敘述、程式及輸出連在一起；Knit/render 依文件的執行順序產生報告。可重現還需要資料來源、相對路徑、套件版本與處理紀錄。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

先準備一份可重跑的 Week 1–3 script；確認 Git 安裝，使用自己的練習 repository，不把密碼、token 或私人資料寫入檔案。

來源與延伸：公開教材章節 ↗

教材、資料與工具

教材包含 RStudio Git 操作、commit、push／pull、branch 與 RMarkdown HTML 輸出；套件還原另見 External usage。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 開啟 project 並確認 repository root；先查看 status／diff，知道哪些檔案即將被記錄，不把產生的大型原始資料任意推上遠端。
  2. 建立簡單 Rmd，加入標題、研究問題、資料來源及 code chunk；把讀檔與分析放進文件，避免依賴 Console 裡現有物件。
  3. 逐段確認 chunk 的輸入和輸出，再 Knit 成 HTML；區分顯示 code 的設定與是否執行 code，不用隱藏錯誤代替修正。
  4. 檢查地圖、表格、來源和方法是否一起出現，記錄套件版本；在新 session 重跑，確認文件不依賴手動操作。
  5. 檢查 diff，建立描述清楚的 commit；依教材同步自己的遠端，理解若兩邊都改檔案，可能需要處理衝突。

來源與延伸：公開教材章節 ↗

成果如何解讀？

可重現報告的價值是讓讀者追查結果如何產生。只交一張 PNG，或只有程式卻沒有資料來源與環境說明，都不足以讓另一位讀者完整重建分析。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • Knit 找不到物件：將建立物件的程式納入文件，按順序執行；檢查工作目錄和相對路徑。
  • Git 驗證方式與舊教材不同：查目前 GitHub 官方登入文件，不照抄過期的密碼登入指令。

另一台電腦能從 README 找到資料、還原套件並產生報告嗎？能指出某張圖對應的 chunk 與 commit 嗎？

來源與延伸：公開教材章節 ↗

建議保留的成果（非新增作業）

Week 05 · 2026-11-05

讓地圖回答問題

Lecture: Cartographic principles
Practical: Map making
Presenter: Andy MacLachlan

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • 製圖要先有比較問題，再決定符號、色階、分類與圖例。Choropleth 的每個面代表統計單位，面積大不代表人數多，原始件數與標準化比率回答不同問題。
  • Attribute join 根據識別碼配對；spatial join 根據空間關係配對。點落在面內、面相交與 buffer 距離的定義不同，會改變統計結果。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

熟悉 sf 物件、join、CRS 及 group summary。先草畫想呈現的地圖，寫出研究範圍、變數、分母與比較對象。

來源與延伸：公開教材章節 ↗

教材、資料與工具

公開教材使用 OSM、Airbnb、London boroughs 等資料；live 章節已說明更新至 tmap 4。不要將舊版 tmap 參數直接混入新環境。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 取得章節資料並篩選目標類別與研究區域，記錄下載版本；檢查位置、重複資料及缺值。
  2. 確認點與面 CRS 一致，按問題決定 spatial relationship，將點分配到行政區；核對邊界點和沒有配對的點。
  3. 每區計算需要的量，區分 raw count、per-area density 與其他 rate；若有分母，檢查它是否匹配相同年度和區域。
  4. 用 tmap 建立圖層、符號和圖例，加入標題、來源、單位和必要的比例尺；先確保語意正確，再調整美觀。
  5. 比較兩種分類或指標版本，觀察哪些區域排名或視覺重點改變；匯出靜態圖並檢查文字、圖例和留白。

來源與延伸：公開教材章節 ↗

成果如何解讀？

地圖中的高值可用來提出問題，不能單憑顏色宣稱因果。讀者應能從圖例知道「比較的是什麼」，並從來源知道「資料來自何時、何處」。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • 地圖看起來對，但用錯變數：確認 plotted column、標籤與單位一致，尤其是數量和密度。
  • 點數超出原始資料：檢查一對多的 spatial join；邊界點可能匹配多個面，需明確記錄分配規則。

能說明分類方式、分母、色階和空值顯示嗎？拿掉標題後，讀者仍能從圖例理解變數嗎？

來源與延伸：公開教材章節 ↗

建議保留的成果（非新增作業）

一張正式 thematic map、一張設計對照圖及方法與資料限制說明。

Week 06 · 2026-11-19

點事件是群聚、分散還是隨機？

Lecture: GI Science 1: Point Pattern Analysis
Practical: Detecting Spatial Patterns (Points)
Presenter: Claire Dooley

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • Point pattern analysis 研究事件的位置。KDE 描述平滑後密度，quadrat 以格網計數，Ripley’s K 觀察不同距離尺度；不同方法各有參數與假設。
  • CSR 是 complete spatial randomness，CRS 是座標參考系統。比較隨機性之前，要先定義 observation window 與事件的可觀測範圍。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

複習 CRS、空間篩選與事件去重。先問資料如何被記錄：資料稀少可能是觀察不足，不一定是實際事件少。

來源與延伸：公開教材章節 ↗

教材、資料與工具

章節使用 London Blue Plaques、borough boundaries 與 spatstat；另有 KDE、quadrat、Ripley’s K、DBSCAN 的比較。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 讀入點與研究區邊界，檢查重複座標、區外點和 CRS；保留清理前後點數及每項排除理由。
  2. 先在全圖檢查資料，再選適合的 borough 作為 observation window；不要用任意矩形把實際不可觀測区域算進面積。
  3. 製作 KDE，記錄 bandwidth；用至少兩個尺度做敏感度比較，理解平滑程度如何改變看到的高密度區。
  4. 做 quadrat 或距離尺度分析，閱讀 null model、模擬 envelope 及邊界處理設定；把圖形與檢定結果一起看。
  5. 如讀 DBSCAN 延伸，說明參數對群集的影響；區分演算法找到的群集與統計上對隨機基準的偏離。

來源與延伸：公開教材章節 ↗

成果如何解讀？

相鄰地區的數值是否相似？

Lecture: GI Science 2: Spatial Association and Autocorrelation
Practical: Spatial Autocorrelation (Continuous observations)
Presenter: Claire Dooley

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • 本週分析的是附在空間單位上的數值，和上週直接研究點的位置不同。必須先把事件轉成各區指標，再建立鄰近關係。
  • Global Moran’s I 描述整體自相關；Local Moran’s I 指出局部群聚或異常。Getis–Ord 與 Geary’s C 有不同統計定義，不要把名稱不同的結果視為同一張圖。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

來源與延伸：公開教材章節 ↗

教材、資料與工具

教材以 London wards、Blue Plaques 指標示範 weight matrix、Moran’s I、Geary’s C、Getis–Ord 及局部統計。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 整理 ward 邊界與屬性，確認一區一列，處理 NA；保留零件數區域，避免因無事件而直接刪除。
  2. 計算區域指標並確認分母與單位，畫初步分布圖；檢查是否是行政區大小在主導件數模式。
  3. 定義 neighbours 和 weights，檢查沒有鄰居的區域、連通性與標準化方式；固定資料排序，讓權重與觀察一一對應。
  4. 計算全域指標與相應檢定，記錄假設、方向與推論方式；不要只抄 statistic 而沒有參照基準或 p-value。
  5. 閱讀局部分析，分開呈現 cluster type 與 significance；檢查權重或尺度改變後的結果，討論多重局部檢定。

來源與延伸：公開教材章節 ↗

成果如何解讀？

High–High 描述高值區與高值鄰近區的組合，不等於所有高值都是顯著群聚。空間權重是分析定義的一部分，要與結果一起報告。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • 資料排序和 weights 不一致：以地區 ID 檢查，重排／刪列後重新建立權重。
  • 把點群聚和數值自相關混為一談：先確認研究的是事件位置，還是區域屬性。

Week 08 · 2026-12-03

以模型解釋空間關聯

Lecture: GI Science 3: Explaining Spatial Patterns
Practical: Explaining Spatial Patterns
Presenter: Ruth Neville

來源與延伸：2026/27 Moodle（需登入）↗

概念與分析問題

  • Regression 將結果變數與解釋變數連結；係數需帶單位、條件與不確定性。控制了幾個變數仍不等於建立因果。
  • 模型殘差可暴露未解釋的空間結構。Spatial lag、spatial error 與 GWR 是不同建模思路，要從研究問題和診斷選擇，不只是追求較高 fit。

來源與延伸：公開教材章節 ↗

課前準備（學習建議）

複習相關、散布圖、線性迴歸與 Moran’s I。先用一句話定義 outcome、predictors、空間單位、時間與假說。

來源與延伸：公開教材章節 ↗

教材、資料與工具

教材以 London ward GCSE 表現與其他區域變數示範 regression、假設診斷、spatial models 及 GWR。它是公開教材例子，不代表正式考題。

來源與延伸：公開教材章節 ↗

展開：逐步操作流程（學習指南）
  1. 讀入、清理並核對各變數的定義及樣本；列出缺值造成的排除，保證合併後仍是一區一列。
  2. 畫散布圖、分布圖與地圖，建立有研究理由的 baseline model；先解釋係數符號、單位及估計的不確定性。
  3. 依章節檢查 linearity、殘差分布、multicollinearity、homoscedasticity 與 errors independence，记錄發現，而非只寫 passed。
  4. 對殘差做空間診斷，明確定義 weights；如果存在結構，先考慮資料、漏變數與研究機制，再比較 spatial model。
  5. 比較模型的研究意義、診斷與限制；GWR 作延伸閱讀時，另說明局部估計與尺度，不把所有模型堆在同一結論裡。

來源與延伸：公開教材章節 ↗

成果如何解讀？

區域平均的關聯不能直接推論個人行為。結論應是「在這份資料、變數及模型條件下觀察到的關聯」，並交代殘差、缺值和空間尺度限制。

來源與延伸：公開教材章節 ↗

展開：常見錯誤與自我檢核
  • R² 高就當作模型正確：還要檢查假設、研究設計及 outliers；加入更多變數不是自動改善解釋。
  • 把局部係數地圖當成確定因果：先看不確定性、樣本支持與模型條件。

能用完整句子解釋一個係數嗎？能說明為何使用某個 spatial model，以及它仍沒有解決什麼嗎？

常用術語：定義、意義與限制

GIS / GIScience
GIS 是處理地理資訊的系統與工具；GIScience 關注表示、測量與分析的原理。 來源 ↗
Vector / raster
前者用點線面，後者用格網。選擇應匹配研究現象和資料支持尺度。 來源 ↗
Geometry / attribute
Geometry 表達位置與形狀；attribute 是附在物件上的變數。先辨識一列代表什麼。 來源 ↗
CRS / EPSG
CRS 是座標參考系統，EPSG code 是識別方式之一。標籤與真正座標轉換不同。 來源 ↗
Resolution / extent
解析度是格網尺度；extent 是涵蓋範圍。較密的圖像不代表較可靠的測量。 來源 ↗
Join / clip
Join 配對資料；clip 依幾何裁切。先決定要增加屬性、選物件還是改幾何。 來源 ↗
Count / density / rate
件數、每面積密度和有特定分母的比例不能互換；必须報告單位與分母。 來源 ↗
CSR / observation window
CSR 是完全空間隨機性；window 定義觀察區。它們不是座標參考系統 CRS。 來源 ↗
Bandwidth
KDE 的平滑尺度。改變它會改變密度圖，因此需記錄並比較。 來源 ↗
Weights / spatial lag
Weights 定義鄰近影響；spatial lag 將鄰近數值按權重組合。意義依定義而變。 來源 ↗
Global / local statistics
全域描述整體，局部定位差異或異常；局部顯著性與高值並不相同。 來源 ↗
Residual / association / causation
殘差是模型未解釋的部分；關聯不等於因果，需要研究設計支持。 來源 ↗
MAUP / ecological inference
彙整單位改變可能改變結果；區域關聯不能直接推到個人。這是尺度與推論限制的檢核。 來源 ↗
Reproducibility / renv
以資料、程式、環境及說明重建結果；renv 支持套件環境，不保證資料來源與研究方法正確。 來源 ↗

  • Week 10：主張與證據對照表、完整方法檢核清單及尚待釐清問題。

從讀到會做：建議的每週節奏

  • 課前：閱讀本週 learning outcomes，辨識資料、方法與未知名詞；下載必要資料並確認環境。

  • 課後：從新 session 重跑，做一個小型參數或資料對照，用自己的話解釋結果並補上來源。
  • Reading Week 之後：依 Moodle practice exam 實際題目與 weekly homework 指示安排練習，不以公開教科書舊版 homework 當成本屆 deadline。

考前能逐項回答的問題

  • 資料：誰／什麼是一個 observation？時間、地理範圍、樣本、缺值、授權與單位是什麼？
  • 空間：CRS 和距離單位是什麼？有哪些尺度、邊界、解析度、鄰近或 observation window 決定？
  • 方法：為何這個方法適合問題？輸入格式、關鍵參數、假設、null model 與診斷是什麼？
  • 結果：數值與圖形各代表什麼？顯著性、實質影響、不確定性與因果是否被混淆？
  • 可重現：程式、資料位置、套件版本與報告能否從頭重跑？每張圖有來源和方法嗎？
  • 正式規則：是否重新查過最新 brief、時間、工具、引用與提交方式？任何不明規則先向 module team 確認。
