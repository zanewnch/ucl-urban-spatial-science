一、這門課具體在做什麼？ 官方課程來源 ↗

你會從城市或空間資料開始，先描述資料的型態與分布，再選擇合適的統計工具，建立模型、檢查關係，最後把模型結果轉化成可以解釋的 spatial／urban insight。它不是只背公式，而是訓練你判斷「這份資料適合怎麼分析」以及「分析結果能不能支持原本的研究問題」。

官方明確說明這是一門介紹 statistical and mathematical tools 的碩士課程，目標是建立概念理解，而不是要求非常進階的 technical mathematics；官方也表示不假設學生已有大量先備知識。

二、會學到哪些統計與數學方法？ 官方課程來源 ↗

  • Data description and representation：理解資料如何被整理、描述與呈現。
  • Probability distributions：用機率分布理解不確定性與資料可能的生成型態。
  • Hypothesis testing：把研究問題轉成可檢驗的統計問題，理解檢定與結果解讀。
  • Linear algebra：建立後續模型與多變量分析需要的矩陣／向量概念。
  • Measuring relationships：衡量變數之間的關係，並判斷關係的強弱與限制。
  • Regression：用迴歸建立解釋或預測模型。
  • Multiple regression：同時處理多個解釋變數，理解控制其他因素後的關係。
  • Multilevel regression：處理具有層級結構的資料，例如個體位於 neighbourhood、neighbourhood 位於城市。
  • Dimensionality reduction：把複雜、多變量資料轉成較容易理解的低維結構。
  • Clustering：依資料特徵找出群組或型態，不預先假定每筆資料屬於哪一群。

三、會使用哪些工具？ 官方課程來源 ↗

  • Python：官方列出的主要程式工具，用於統計與資料分析實作。
  • Jupyter：以 notebook 形式交錯撰寫程式、分析與解釋。
  • GitHub／Git：用於版本控制、保存分析工作與協作。
  • Podman：官方 software list 中列出的 container 工具。

Catalogue 列出的工具為 Python、Jupyter、Git/GitHub 與 Podman；本屆 Week 1 Practical 另外明確提供 R 或 Python 兩種版本，可擇一完成。2026/27 Week 1 語言選擇 ↗

四、上課方式與實作 官方課程來源 ↗

  • Term 1、15 credits、FHEQ Level 7，官方標示為 in-person。
  • 10 次 weekly lectures，加上 10 次 weekly practical sessions。
  • 實作的角色是把統計概念放回 spatial／urban context，練習從資料、模型到 interpretation 的完整流程。
  • 官方頁面沒有公開每一次 practical 的逐週題目或固定資料集，因此這張 card 不把未公開的案例自行寫成正式課綱。

五、學完後應該能做到什麼？ 官方課程來源 ↗

  • 描述與呈現城市／空間資料。
  • 理解並選用適合研究問題的統計與數學工具。
  • 建立 regression、multiple regression 或 multilevel regression 等模型。
  • 用 dimensionality reduction 與 clustering 探索複雜資料。
  • 從模型輸出推導 spatial／urban insight，而不是只報告一個數字。
  • 辨認資料、模型假設與解釋之間的限制。

六、需要什麼先備知識？ 官方課程來源 ↗

官方課程描述以「conceptual understanding rather than technical mathematics」為定位，並寫明 little or no prior knowledge assumed。因此不需要先成為統計或數學專家；但先複習平均數、變異、機率、圖表閱讀、correlation 與 regression 的基本直覺，會讓 Term 1 的進度比較容易跟上。

Python／Jupyter 環境設置參考

以下保留往年 Python setup 範例，命令中的 sds2025 代表 2025 版本；本屆環境請先核對課程平台與 Moodle 的當年指示。CASA 平台安裝頁 ↗

CASA0007 公開教材要求使用 CASA Computing Environment；它推薦 Podman container，讓全班 Python 與函式庫版本一致。不要先自行 pip 安裝一堆套件，以免和課程 container 發生版本衝突。以下是 Windows 的可操作路徑；Mac/Linux 請依同一官方安裝頁切換作業系統指示。

開始前：檢查電腦 官方課程來源 ↗

  • 官方健康檢查的基本門檻：至少 16GB RAM、超過 30GB 可用空間；Windows 10 Home 是常見虛擬化問題來源。較新年度教材曾建議預留更多空間，先確認 CASA setup health check。
  • Windows 開啟 Start，搜尋「Turn Windows features on or off」，啟用 Virtual Machine Platform 和 Windows Hypervisor Platform，重新開機。另依 UCL 指引安裝 WSL2；若校務 IT 管理此電腦，先確認校方政策。

安裝所需程式 官方課程來源 ↗

  1. 安裝 Windows Terminal、Podman Desktop、Git 和 GitHub Desktop。GitHub Desktop 設定用於課程的 GitHub 帳號。
  2. 啟動 Podman Desktop，完成初始設定；開啟新的 Windows Terminal（PowerShell 分頁）。
  3. 建立並啟動 Podman 虛擬機器，然後拉取一個測試 image：
podman machine init
podman machine start
podman run hello-world

看到 Hello Podman World 即通過 Podman 基本測試。若 machine 已建立，第二次開始只需 podman machine start。

啟動課程 JupyterLab 官方課程來源 ↗

  1. 先建立一個專門放 CASA0007 notebooks 的資料夾，在 Windows Terminal 用 cd 進入該資料夾；container 會把目前資料夾掛載成 notebook 工作目錄。
  2. 以下是公開 CASA Computing Platform 指引中的 x64/AMD64 範例命令（整行貼進 PowerShell）。它會下載約數 GB 的課程 image，首次啟動需等候：
podman run --rm -d --name sds2025 -p 8888:8888 -v "${PWD}:/home/jovyan/work" jreades/sds:2025-amd start.sh jupyter lab --LabApp.password='' --ServerApp.password='' --NotebookApp.token=''

開啟瀏覽器到 http://localhost:8888，新增 Python 3 notebook。Apple Silicon/M 系列請依官方頁使用 ARM image。此命令使用文件列出的 sds2025 image；2026/27 Moodle 若提供更新 tag 或啟動指令，以當年度課程公告為準。

確認 Notebook 真正接上課程 Python 官方課程來源 ↗

在新 notebook 執行以下 cell。版本號會隨課程 image 更新；重點是每行可匯入、Jupyter kernel 顯示為 Python 3：

import sys
import numpy as np
import pandas as pd
import scipy
import statsmodels
import sklearn

print(sys.version)
print("NumPy", np.__version__)
print("pandas", pd.__version__)
print("SciPy", scipy.__version__)
print("statsmodels", statsmodels.__version__)
print("scikit-learn", sklearn.__version__)

完成後用 podman stop sds2025 停止環境；因為用了 --rm，container 會移除，但掛載的 notebook 留在本機資料夾。

常見卡點 官方課程來源 ↗

  • podman machine start 無法啟動：先確認兩個 Windows virtualization feature 已啟用並重新開機；依 CASA platform common problems 檢查 WSL2／BIOS virtualization。若提示 machine configuration/permission 錯誤，先看錯誤訊息再依官方指南重建命名 machine。
  • podman: command not found：完全關閉並重新開啟 Terminal，確認 Podman Desktop 已安裝並啟動。
  • 瀏覽器連不到 8888：確認 podman ps 有 sds2025，且啟動命令中的 port mapping 是 -p 8888:8888。
  • Notebook 找不到套件：確認 kernel 是 container 內的 Python 3；先別任意切換本機 Python，並對照 Moodle 的當年 setup 指示。
