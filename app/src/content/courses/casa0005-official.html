01 · 課程定位與七項學習成果

Catalogue 確認本課為 Term 1、15 credits、FHEQ Level 7、in-person；主體使用 R，亦涵蓋 QGIS 基本概念。不要求先有 GIS 或 R 知識，但會快速進入進階方法。

來源與延伸：正式課程資料 ↗

Moodle 概述將 geographic representation、GIScience、spatial analysis、raster／vector 方法與近期的視覺化、互動製圖串在一起。讀這門課時，應同時練「資料操作」與「對方法、測量及限制的解釋」。

來源與延伸：2026/27 Moodle（需登入）↗

七項官方成果，以及如何檢查自己學會了

  • 1. QGIS 與 R 工作知識：官方要求能用兩者支持 GI Science 技術。學習檢核：能在軟體中讀入資料、辨認圖層與欄位，並用 R 留下可重跑紀錄。
  • 2. 高標準地圖：官方要求製作合適的地理資訊視覺化。學習檢核：圖例、單位、來源、分類與符號可讀，且能解釋設計決定。
  • 3. 空間資料管理：包含 attribute–geometry join、清理、檔案格式與參考系統轉換。學習檢核：能證明配對正確，且轉換前後位置與資料意義一致。
  • 4. 解讀與應用空間分析：官方例子有 autocorrelation／hot spot、areal interpolation、point-in-polygon／buffer。學習檢核：從問題選方法，交代輸入、參數與限制；這些例子不等於每項都有本屆獨立實作週。
  • 5. 表達與不確定性：官方要求評估 geographic data 的常見問題。學習檢核：能指出解析度、行政區、資料涵蓋與缺值如何影響結論。
  • 6. 空間統計推論與批判：官方要求應用並評析 spatial statistical techniques。學習檢核：區分描述、顯著性、模型關聯與因果主張。
  • 7. 全球空間資料多樣性：官方要求評估各種資料的優點與缺點。學習檢核：比較兩個來源的時間、尺度、定義、覆蓋與適用問題。

來源與延伸：2026/27 Moodle（需登入）↗

這些概念如何連在一起？

本頁的讀書順序是：研究問題 → 空間表示與測量 → 資料整理 → 地圖／摘要 → 適當方法 → 不確定性與結論 → 可重現報告。Vector 和 raster 是表示方法；GIS 是處理工具；GIScience 問表示與分析是否合理；製圖是溝通；版本與報告則使結果可追查。

03 · 安裝環境與第一次成功執行

公開教材的 External usage 指定 R、RStudio、從 GitHub clone project，以及使用 renv::restore() 還原 renv.lock 中的套件。也可只下載單章 Rmd、該章套件與資料。部分資料因大小限制不在 GitHub，須照章節另行取得。

來源與延伸：公開教材章節 ↗

安裝順序與成功判斷

  1. 1. 安裝 R：R 是實際執行程式的環境。依自己的作業系統選官方安裝包；成功判斷是在 RStudio Console 能取得 R.version.string。
  2. 2. 安裝 RStudio Desktop：它提供 editor、Console、Files 與圖形介面。開啟後確認找到 R，建立小型 script 並執行，不只看應用程式有開啟。
  3. 3. 安裝 Git：完整 clone／版本管理流程需要 Git。依目前官方安裝說明操作，重新開啟 RStudio 後檢查 Version Control 的 Git 選項。
  4. 4. 取得課程 project：RStudio → File → New Project → Version Control → Git，使用教材 repository URL，將專案放在自己可辨識的位置，再開啟 .Rproj。
    CASA0005 課程 GitHub repository ↗
  5. 5. 還原套件：在課程 project 的 Console 安裝 renv 並執行 renv::restore()。閱讀它即將安裝的版本與訊息；不要以升級全部套件來取代教材環境。
  6. 6. 取得該週資料：開啟對應章節，按章節資料連結下載並解壓縮；檢查 script 引用位置與實際路徑一致，保留原始資料。
  7. 7. QGIS：使用官方下載入口；用它檢視圖層、屬性與 CRS。QGIS 是本課學習成果的一部分，但不由此推定考試允許或要求使用。

第一次執行的最小閉環

  • 先確認 project 根目錄與輸入檔案存在；read data 之後查看列數、欄位、geometry type、CRS 和 extent。
  • 先畫只有幾何的圖，確認位置合理，再增加屬性或分析；複雜圖層之前先驗證最小输入。
  • 保存 script，輸出圖與資料檢查紀錄，再用新 session 從頭執行。成功標準是讀檔、檢查、出圖、重跑全部可完成。

10 · 常見問題與診斷順序

讀不到檔案或下載資料不全？

先用 getwd() 與 file.exists() 檢查自己的 project 與檔案路徑；檢查是否已解壓縮，以及資料是否本來就不在 repo。教材作者的絕對路徑不是你的電腦路徑。

來源與延伸：公開教材章節 ↗

套件載入失敗、範例參數不相容？

先記錄完整錯誤、R 和 package 版本，再核對 renv.lock／教材版本；用 renv 還原而非連續盲目升級。tmap 章節已更新至 version 4，舊版範例可能不同。

來源與延伸：公開教材章節 ↗

圖層錯位、距離離譜？

先檢查原始 CRS、座標值、單位與 extent；只更改 CRS 標籤不會轉換數值。沒有來源的 CRS 不應靠視覺猜定。

來源與延伸：公開教材章節 ↗

Join 後 NA 或列數變多？

查 key、空白字元、型態、地區年度、重複與未配對資料；空間 join 再查多重相交與邊界規則。先找到原因，不直接補零或刪列。

來源與延伸：公開教材章節 ↗

Knit 失敗但 Console 可以跑？

Console 可能保留之前的物件，render 卻依文件順序執行。將讀取、清理和建立變數的步驟放進文件，核對相對路徑與 chunk 順序。

來源與延伸：公開教材章節 ↗
