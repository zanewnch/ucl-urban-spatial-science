07A · 公開實作教材裡具體有哪些內容？

這一節直接盤點 Andy MacLachlan、Adam Dennett 與 Claire Dooley 的公開 CASA0005 handbook。主要實作主線是 Chapter 1–8；以下列的是教材頁面實際涵蓋的主題與示例，方便你判斷要讀哪章。GitHub repository 還放有教材原始檔及補充 R Markdown 文件。

來源與延伸：公開 handbook ↗ · GitHub repository README 與檔案清單 ↗

教材部分具體涵蓋內容直接閱讀
起步、軟體與 project課程及軟體說明、R／RStudio 安裝、建立 project、取得教材、套件與資料準備；教你用 project 相對路徑讀檔，並說明教材的使用方式。Software installation ↗ · External usage ↗
Chapter 1 · Geographic InformationGIS 資料格式、資料來源與前處理；以 London borough 邊界和 fly-tipping CSV 為例，在 QGIS／R 讀取空間圖層、檢查資料、按地區識別碼 join，並畫出基本地圖。本站閱讀 Chapter 1 ↗ · 原始公開教材 ↗
Chapter 2 · Introduction to RR 基本運算與資料物件、CSV 清理及整理、`sf` 空間資料操作，並以實作範例練習資料轉換和地圖。閱讀 Chapter 2 ↗
Chapter 3 · Spatial descriptive statistics載入及操作 raster、把格網資料與位置／區域資料搭配，抽取並摘要數值，以直方圖等方式檢視分布；章節使用氣候資料範例。閱讀 Chapter 3 ↗
Chapter 4 · Git, GitHub and RMarkdown用 Git 記錄版本、用 GitHub 管理遠端 repository，並以 RMarkdown 組合說明文字、程式和輸出，產生可追查的分析報告。閱讀 Chapter 4 ↗
Chapter 5 · Map making用 OpenStreetMap（OSM）、Airbnb 與區界資料製作地圖，學習 `tmap` 的圖層與符號表達，並比較靜態／互動呈現及製圖選擇；目前公開章節採 tmap 4 語法。閱讀 Chapter 5 ↗
Chapter 6 · Detecting spatial patterns以 London Blue Plaques 等點事件示範空間點模式；對照 kernel density estimation（KDE）、quadrat counts、Ripley’s K 與其他群聚方法，理解觀察範圍、尺度與參數如何影響判讀。閱讀 Chapter 6 ↗
Chapter 7 · Spatial autocorrelation從區域連續變數建立 spatial weights，練習全域／局部 Moran’s I、LISA，以及 Geary’s C、Getis–Ord 等統計，並解讀空間群聚與異常值。閱讀 Chapter 7 ↗
Chapter 8 · Explaining spatial patterns使用 London wards 的 GCSE 等區域資料練習假設檢定、迴歸與模型診斷；檢查殘差空間自相關，並介紹 spatial lag、spatial error 與 GWR 等模型。閱讀 Chapter 8 ↗

Repository 另外放了哪些東西？

GitHub 不只有線上 handbook：它也放著產生教材的 `.Rmd` 原始章節、RStudio project 與套件描述檔、插圖／輸出檔，以及一批補充 practical 原始文件。README 檔案清單可見 multiple linear regression、assignment resources、extra material、QGIS maps、舊版 tmap v3、functions、interactive maps、bounding box／basemap、past questions 和 field trip 等文件。

這些補充檔案是 repository 收錄的教材或歷史材料；它們出現在清單中，不代表每份都是 2026/27 的指定週次、當前考試題目，或 Moodle 已要求完成的作業。Week 9 的 GIS methods review 和 Week 10 Critical GIS 仍依本屆 Moodle 整理；公開 handbook 的 Chapter 1–8 與它們可作為複習參考。
