Term 2 CASA optional 課程內容

CASA0002

Urban Simulation 官方課程來源 ↗

已選Term 215 creditsCASA optionalSmart Cities and Urban PolicyUrban Modelling and SimulationFHEQ Level 7

以 complexity science、spatial interaction models 與 network science 建立城市系統模型，分析人與地點之間的流動、交通節點、通勤網絡、社群結構與 resilience。

Complete module dossierSpatial interaction models 與 network science
模型在做什麼Spatial interactionNetworksPython 與實作先備知識學習成果Assessment

一、這門課具體在模擬什麼？ 官方課程來源 ↗

課程用 mathematical modelling 把城市視為一個具有互動、流動與複雜結構的 system。你會處理 people／places 之間的 interaction，以及個別互動如何形成整體 urban structure；官方特別以 transport、commuting flows、transport-node centrality、resilience 與 community detection 作為應用脈絡。

二、Spatial interaction models 官方課程來源 ↗

  • 理解 flows 如何在不同 area 之間發生，並把各地的 location characteristics 與 spatial distribution 納入模型。
  • 分析 constraints 與 parameters，理解模型如何受到條件限制。
  • 接觸 entropy maximisation 與 retail application。
  • 用 Python 實作、calibrate 並選擇合適的 spatial interaction model。
  • 理解模型是對城市互動的抽象，不是城市本身；因此要檢查假設與解釋限制。

三、Network science 官方課程來源 ↗

  • 把 complex system 表示成 nodes、links 與 adjacency matrices。
  • 計算與解釋 centrality，區分 local／global measures。
  • 使用 community detection 找出網絡中的群組結構。
  • 理解 random networks、null hypotheses 與不同 link types。
  • 分析 network resilience，並用 Python 做 spatial network visualisation。
  • 認識 Agent Based Modelling／Cellular Automata 與 network modelling 的關聯。

四、Python 與課堂實作 官方課程來源 ↗

  • 官方課程以 code-based practical 為核心，會用 Python 實作與校準模型、處理矩陣／向量與視覺化 network。
  • 課程每週同時包含 lecture 與 practical，實作會把數學概念轉成可執行的程式。
  • 這門課需要能閱讀、修改與執行提供的 Python code；不是只看理論。

五、先備知識與修課順序 官方課程來源 ↗

  • 非程式背景學生官方 strongly advised 先修 CASA0013 或同等能力。
  • 需要 basic Python 或其他程式語言能力。
  • 需要複習 matrices、vectors 等數學表示法，才能跟上 model 與 network content。

六、學完後應該能做到什麼？ 官方課程來源 ↗

  • 建構、calibrate 與選擇 spatial interaction models。
  • 說明模型 constraints、parameters、entropy maximisation 與 urban application。
  • 建構 networks 與 adjacency matrices，並解釋 centrality。
  • 用 community detection 分析群組結構。
  • 討論 network resilience 與 spatial network visualisation。
  • 辨認 spatial interaction、ABM、CA 與 network approaches 的差異與關係。

七、Exam 與 assessment 官方課程來源 ↗

  • 2026/27 目前列為 100% Coursework，numeric marks。
  • 公開 module page 沒有確認 coursework 的具體形式是 coding project、report、上機考或 presentation；要以當年度 assessment brief 為準。

官方來源： UCL Module Catalogue：CASA0002

CASA0011

Agent Based Modelling for Spatial Systems 官方課程來源 ↗

已選Term 215 creditsCASA optionalUrban Modelling and SimulationFHEQ Level 7

用 Agent Based Modelling（ABM）建立與評估城市空間中的 agents、規則與互動，從 cellular automata、ODD protocol 到 ABM + GIS，應用在交通、土地使用、行人、危機與基本流行病情境。

Complete module dossier從 individual agents 到 urban simulation
ABM 工作模型主題城市應用工具先備知識學習成果Assessment

一、這門課具體在做什麼？ 官方課程來源 ↗

課程是 hands-on：practicals 會先建立 example models，再逐步把模型改成你自己的 simulation。你會定義 agents、環境、規則與互動，執行 simulation，觀察 aggregate outcomes，並評估模型是否能回答原本的 urban question。

核心不是把 ABM 當成「預測未來的黑盒子」，而是理解 micro-level behaviour 如何產生 macro-level spatial patterns，以及模型假設會如何影響結果。

二、會學哪些 ABM 主題？ 官方課程來源 ↗

  • Cellular automata。
  • ODD protocol：清楚描述 model Overview、Design concepts 與 Details。
  • Competition among agents。
  • Optimisation、forecasts 與 predictions。
  • ABM 與 GIS 的結合。
  • ABM 的 history、current trends 與 model outcomes evaluation。

三、可以拿來模擬哪些城市問題？ 官方課程來源 ↗

  • Pedestrian movement。
  • Traffic／transportation。
  • Land use。
  • Evacuations 與 crises。
  • Basic epidemiology。
  • 其他需要模擬人、車、土地或政策互動的 spatial systems。

四、會使用哪些工具？ 官方課程來源 ↗

  • NetLogo：常見的 agent-based modelling environment。
  • MESA：Python ecosystem 中的 ABM framework。
  • 官方寫法是 NetLogo and/or MESA；實際採用哪一個要以當年度 teaching setup 為準。
  • ABM + GIS 會讓 simulation 的 agents、環境與地理空間位置連起來。

五、先備知識 官方課程來源 ↗

  • 非程式背景學生官方 strongly advised 先修 CASA0013。
  • 需要能理解基本 programming logic、變數、函式與 model rule。
  • 若要用 MESA，Python 經驗會很有幫助；若使用 NetLogo，仍需要理解 simulation logic。

六、學完後應該能做到什麼？ 官方課程來源 ↗

  • 設計、實作與評估 ABM。
  • 使用 ODD protocol 清楚說明 model design。
  • 把 agents、rules、competition、optimisation 與 forecast 放進 spatial context。
  • 連結 ABM、cellular automata、GIS 與 urban applications。
  • 解釋 individual behaviour 如何形成 aggregate urban pattern。
  • 批判性評估 simulation outcomes 與模型限制。

七、Exam 與 assessment 官方課程來源 ↗

  • 2026/27 目前列為 50% Coursework + 50% Dissertations, extended projects, and reports，numeric marks。
  • 公開頁面沒有確認各部分是 coding exercise、model report、presentation 或其他固定格式；正式 brief 以 Moodle 與 module team 為準。

官方來源： UCL Module Catalogue：CASA0011

CASA0025

Building Spatial Applications with Big Data 官方課程來源 ↗

已選Term 215 creditsCASA optionalBig Data同時列為額外 CASA optionalFHEQ Level 7

從 SQL、spatial database、大型資料處理、web mapping 到 cloud computing，建立能處理大規模空間資料並呈現互動結果的 spatial application。

Complete module dossier把 large spatial data 變成可互動的 web application
課程工作Database 與 SQLWeb 與 cloudGroup project先備知識學習成果Assessment

一、這門課具體在做什麼？ 官方課程來源 ↗

課程處理的是超過一般 local machine compute／storage 能輕鬆處理的 spatial data。你會走完整 cloud geospatial workflow：把資料 import、存進合適的 database、用 SQL／spatial query 分析，再把結果做成 interactive web visualisation 或 spatial application。

重點是從「分析一份資料」走向「設計一個能處理、服務與呈現大型空間資料的系統」。

二、Database、SQL 與空間資料 官方課程來源 ↗

  • 理解 databases 如何儲存與分析 spatial data。
  • 用 SQL 查詢、篩選、整理與分析大型資料。
  • 處理 spatially enabled data 與空間查詢。
  • PostGIS 可作為 spatial database 的應用脈絡；但目前 UCL module page 公開確認的是 databases、SQL 與 spatial analysis，沒有把某一個 database product 寫成所有學生的硬性 requirement。

三、Web application 與 cloud computing 官方課程來源 ↗

  • 建立 web-based interaction 與 visualization。
  • 把 spatial analysis 結果放進 interactive map／application。
  • 使用 cloud computing 處理較大的空間資料與分析工作。
  • 理解從資料匯入、分析到互動呈現的全流程，而不只是畫一張靜態地圖。

四、實作與 portfolio 官方課程來源 ↗

  • 使用 large spatial datasets。
  • 完成 interactive group project，形成可放入 portfolio 的成果。
  • 需要同時考慮資料結構、query、分析、web interaction 與使用者如何理解結果。
  • 這門課適合想把 spatial analysis 延伸成 data product、web map 或 cloud application 的學生。

五、先備知識與課程位置 官方課程來源 ↗

  • 目前 course page 的 restriction 為 N/A，沒有列出硬性 prerequisite。
  • 現有 programme dependency／課程脈絡把 CASA0013 或 equivalent programming 放在 CASA0025 前面；因此有基本 programming、資料 pipeline 與 spatial data 概念會比較容易。
  • SQL、database 或 web mapping 經驗不是本頁明確列出的硬性門檻，但會降低學習曲線。

六、學完後應該能做到什麼？ 官方課程來源 ↗

  • 設計能儲存與分析 spatial data 的 database。
  • 用 SQL 處理 large spatial datasets。
  • 把 cloud computing 放進 geospatial workflow。
  • 製作 web-based interactive spatial visualisation／application。
  • 把從 import／analysis 到 interactive presentation 的整條 pipeline 做成可展示的 project。

七、Exam 與 assessment 官方課程來源 ↗

  • 2026/27 目前列為 30% Coursework + 70% Group activity（2 assessments），numeric marks。
  • 公開頁面沒有確認 coursework 或 group activity 的固定格式是否包含 coding、report、demo 或 presentation；正式 brief 以當年度 Moodle 與 module team 為準。

官方來源： UCL Module Catalogue：CASA0025

CASA0006

Data Science for Spatial Systems 官方課程來源 ↗

選修參考Term 215 creditsCASA optionalData VisualisationUrban Modelling and SimulationFHEQ Level 7

進階 spatial data science 與 machine learning module：從 supervised learning workflow、模型評估與 cross-validation，到 tree-based methods、neural networks、graph neural networks、model interpretation 與 MLOps。

Complete module dossier以 machine learning 分析 spatial systems
ML workflow模型方法工具進階主題先修學習成果Assessment

一、這門課具體在做什麼？ 官方課程來源 ↗

課程把 machine learning 放回 spatial systems 與 urban applications，而不是只教一組演算法。你會從定義問題開始，選擇 metrics、切分 train／test data、做 cross-validation、解讀 model，並思考模型在真實城市資料上是否可靠。

它是 CASA0007 Quantitative Methods 之後的進階選修；官方明確預期學生先完成 CASA0007。

二、會學哪些 machine learning 方法？ 官方課程來源 ↗

  • Introductory machine learning concepts。
  • Supervised learning metrics 與完整 workflow。
  • Tree-based methods。
  • Neural networks。
  • Graph neural networks，處理 graph／network 結構的資料。
  • Model interpretation 與 feature selection。
  • Classification／regression 類型的 urban／spatial applications。

三、會使用哪些工具？ 官方課程來源 ↗

  • Python：主要 data science programming tool。
  • Jupyter：以 notebook 進行分析與實作。
  • GitHub／Git：版本控制與協作。
  • Podman：官方 software list 中列出的 container 工具。

四、模型可靠性與 production thinking 官方課程來源 ↗

  • Imbalanced data：資料類別比例不平衡時，評估結果可能如何失真。
  • MLOps：把模型放入較完整、可管理的資料／部署流程。
  • Testing ML systems：檢查 machine learning system 是否按照預期工作。
  • Model interpretation：不要只追求 prediction accuracy，也要理解模型用了什麼訊號、結果能不能被解釋。

五、先修與課程位置 官方課程來源 ↗

  • 官方 restriction：expected to have completed CASA0007 Quantitative Methods。
  • 需要能理解基本統計、資料分析與 model evaluation；Python／Jupyter 經驗會很有幫助。
  • 官方 module page 沒有列出 CASA0013 為硬性 prerequisite，但如果 Python 基礎薄弱，先補 spatial data science foundation 會比較實際。
